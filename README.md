# UnitCellMC.jl

This package allows for classical Markov Chain Monte Carlo simulations of spin models with user-defined lattice geometries.

## Usage

Install using Julia's package manager:

```julia
import Pkg
Pkg.add(url="github.com/swestastic/UnitCellMC.jl")
```

## Notes

Support and documentation are currently quite minimal. There are 1D chain and 2D square lattices examples in `/examples/`. Currently, it only supports the Ising model, with additional support coming in the future.
