UnitCellMC.IsingState — Type
IsingState{S,T<:Real,M<:Integer} <: AbstractState

The mutable configuration of an Ising model simulation: per-site spins and the running totals (energy, magnetization) kept in sync with them as updates are applied.

The running totals are maintained incrementally by apply_update! rather than recomputed from scratch each step, so they must be kept consistent with spins by construction (see initialize_state) and by every code path that mutates spins.

Fields

  • spins::S: Per-site spin values (typically ±1).
  • energy::T: Total energy of the current configuration.
  • magnetization::M: Total magnetization (sum of spins) of the current configuration.

Construct with initialize_state(model, geometry).

UnitCellMC.XYState — Type
XYState{S,T<:Real} <: AbstractState

The mutable configuration of an XY model simulation. Each site stores an angle in radians, while energy and the two Cartesian magnetization components are cached for incremental updates.

The running totals are maintained incrementally by apply_update!, apply_cluster!, and apply_clusters!, so they must be kept consistent with angles by construction (see initialize_state) and by every code path that mutates angles.

Construct with initialize_state(model, geometry).

UnitCellMC.ClockState — Type
ClockState{S,T<:Real} <: AbstractState

The mutable configuration of a ClockModel simulation. Each site stores an integer clock index n ∈ 0:q-1, representing the planar spin at angle θ = 2π n / q; energy and the two Cartesian magnetization components are cached for incremental updates.

The running totals are maintained incrementally by apply_update!, apply_cluster!, and apply_clusters!, so they must be kept consistent with spins by construction (see initialize_state) and by every code path that mutates spins.

Fields

  • spins::S: Per-site clock indices, each in 0:q-1.
  • energy::T: Total energy of the current configuration.
  • magnetization_x::T: Total x magnetization, Σ_i cos(2π n_i / q).
  • magnetization_y::T: Total y magnetization, Σ_i sin(2π n_i / q).

Construct with initialize_state(model, geometry).

UnitCellMC.initialize_state — Function
initialize_state(model, geometry; rng = Random.default_rng())

Build a random initial state for model on geometry, with the running totals (energy, magnetization) computed from scratch to match the configuration.

There is no model-agnostic initialization: each model provides its own method (see State/Initialization.jl), so this fallback throws for any model that does not.

Arguments

  • model: The model supplying the couplings/field and the state type.
  • geometry: The lattice geometry, giving n_sites and the neighbor table.
  • rng: Random number generator for the initial configuration.

Throws

ArgumentError if model does not provide its own initialize_state method. To support a custom model, define initialize_state(model::MyModel, geometry::Geometry; rng) returning a state whose cached totals are consistent with the configuration it builds.

Returns

For models that implement it, a freshly randomized AbstractState whose cached energy/magnetization match its configuration.

source
initialize_state(model::IsingModel, geometry::Geometry; rng = Random.default_rng())

Build a random initial IsingState for model on geometry, with energy and magnetization computed from scratch to match the random spins.

Each site is assigned a uniformly random spin of ±1. Total energy is computed by summing -0.5 * J * spins[i] * spins[j] over every bond incident to every site (the 0.5 avoids double-counting since each bond is visited from both endpoints) plus the field contribution -h * spins[i] per site; magnetization is simply the sum of all spins.

Arguments

  • model: The IsingModel supplying bond strengths J and field h.
  • geometry: The lattice geometry, giving n_sites, bonds, and the neighbor table used to enumerate each site's bonds.
  • rng: Random number generator for the initial spins.

Throws

ArgumentError from validate_model_geometry if model and geometry are incompatible (coupling/field lengths versus the bond templates and unit-cell orbitals).

Returns

A randomly initialized IsingState with energy and magnetization consistent with its spins.

source
initialize_state(model::XYModel, geometry::Geometry; rng = Random.default_rng())

Build a random initial XYState for model on geometry, with energy and both Cartesian magnetization components computed from scratch.

Each site is assigned an angle uniform in [0, 2π). Total energy is -0.5 * J * cos(angles[i] - angles[j]) summed over every bond incident to every site (the 0.5 avoids double-counting) plus the field contribution -h * cos(angles[i]) per site.

Arguments

  • model: The XYModel supplying bond strengths J and field h.
  • geometry: The lattice geometry, giving n_sites and the neighbor table.
  • rng: Random number generator for the initial angles.

Throws

ArgumentError from validate_model_geometry if model and geometry are incompatible.

Returns

A randomly initialized XYState with energy, magnetization_x, and magnetization_y consistent with its angles.

source
initialize_state(model::ClockModel, geometry::Geometry; rng = Random.default_rng())

Build a random initial ClockState for model on geometry, with energy and both Cartesian magnetization components computed from scratch.

Each site is assigned a uniformly random clock index in 0:q-1. Total energy is -0.5 * J * cos(θ_i - θ_j) summed over every bond incident to every site (the 0.5 avoids double-counting) plus the field contribution -h * cos(θ_i) per site, with θ = 2π n / q evaluated through clock_cos.

Arguments

  • model: The ClockModel supplying q, bond strengths J, and field h.
  • geometry: The lattice geometry, giving n_sites and the neighbor table.
  • rng: Random number generator for the initial clock indices.

Throws

ArgumentError from validate_model_geometry if model and geometry are incompatible.

Returns

A randomly initialized ClockState with energy, magnetization_x, and magnetization_y consistent with its spins.

UnitCellMC.SpinUpdate — Type
SpinUpdate{V,M}

A proposed single-site update: change the local degree of freedom at site to new_value.

The proposal carries the change the update makes to the total magnetization in magnetization_change — a scalar for IsingModel, a (ΔMx, ΔMy) tuple for XYModel and ClockModel — because only the model knows how its local values map to magnetization (clock indices, for example, through their lookup tables). apply_update! can therefore keep the state's running totals exact without access to the model.

Every single-site-update model uses this one proposal type; see the update contract under apply_update!.

Fields

  • site::Int: Index of the site to update.
  • new_value::V: The proposed value for that site.
  • magnetization_change::M: The change the update makes to the total magnetization.

UnitCellMC.apply_update! — Function
apply_update!(state, proposal, ΔE)

Apply proposal to state in place, updating the site's degree of freedom along with the running total energy and magnetization.

This is the final step of the single-site update contract shared by every local-update algorithm and model:

  1. propose(rng, algorithm, model, geometry, state) returns a SpinUpdate carrying everything needed to apply the move — including the magnetization change, which only the model can compute;
  2. energy_difference(model, geometry, state, proposal) returns the energy change ΔE;
  3. the algorithm decides acceptance and calls apply_update!(state, proposal, ΔE), a state-layer function that is model-free by construction.

Each state type provides its own method in its State/ file.

Returns

nothing; state is mutated in place.
