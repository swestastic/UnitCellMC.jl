UnitCellMC.average_and_error — Function
average_and_error(values::Vector{Float64})

Compute the bin average and standard error of the mean for a scalar observable's per-bin values.

The error is estimated as sqrt(variance / n_bins), where variance is the sample variance of values (Bessel-corrected, dividing by n_bins - 1).

Arguments

  • values: Per-bin averages for one scalar observable (e.g. energy, magnetization), one entry per bin.

Throws

ArgumentError if fewer than two bins are given.

Returns

A (average, error) tuple.

source
average_and_error(values::Vector{Vector{Float64}})

Compute the elementwise bin average and standard error of the mean for a vector-valued observable's per-bin values (e.g. a correlation function evaluated at each displacement).

Each element of values is one bin's vector of per-displacement (or otherwise per-component) values; these are stacked into an n_disp × n_bins matrix and averaged/errored along the bin dimension.

Arguments

  • values: Per-bin value vectors for one vector-valued observable, one vector per bin, all of equal length.

Throws

ArgumentError if fewer than two bins are given.

DimensionMismatch if the per-bin vectors do not all have the same length.

Returns

An (averages, errors) tuple of vectors, each of the same length as the per-bin vectors in values.

source
average_and_error(values::Vector{Vector{ComplexF64}})

Complex counterpart of the vector method, used for complex-valued observables such as :structure_factor. The real and imaginary parts are averaged and errored independently.

Returns

An (averages, errors) tuple of Vector{ComplexF64}; real(errors) and imag(errors) are the standard errors of the real and imaginary parts.

UnitCellMC.jackknife_samples — Function
jackknife_samples(bin_values::Vector{T}) where T

Compute leave-one-out jackknife samples from per-bin values.

For n = length(bin_values) bins with total total = sum(bin_values), the i-th jackknife sample is (total - bin_values[i]) / (n - 1), i.e. the average of all bins except the i-th.

Arguments

  • bin_values: Per-bin values (scalar or vector-valued, any type supporting sum, subtraction, and elementwise division).

Throws

ArgumentError if fewer than two bins are given.

Returns

A vector of n jackknife samples, one per omitted bin. The element type is determined by the subtraction and division operations.

UnitCellMC.jackknife_stats — Function
jackknife_stats(f::Function, jk_sample_sets::AbstractVector{<:Real}...)

Compute the jackknife estimate and error of a (possibly nonlinear) function f of one or more primary observables, given their jackknife sample sets.

f is evaluated once per jackknife replicate i, taking the i-th sample from each set in jk_sample_sets (as produced by jackknife_samples) as its arguments. The jackknife error accounts for correlations between the observables and for nonlinearity in f, unlike simple error propagation.

Arguments

  • f: A function of length(jk_sample_sets) real arguments, computing the derived quantity from one sample of each underlying observable.
  • jk_sample_sets: One or more jackknife sample vectors (e.g. from jackknife_samples), all of equal length.

Throws

ArgumentError if no sample sets are provided, if the sample sets have different lengths, or if fewer than two jackknife replicates are provided.

Returns

A (value, error) tuple: the jackknife mean of f over all replicates, and its jackknife standard error.

UnitCellMC.analyze — Function
analyze(container::MeasurementContainer, T, N)

Compute primary and derived statistics for all observables recorded in container.

Primary observables (container.data) are reduced to (average, error) pairs via average_and_error and to jackknife sample sets via jackknife_samples. Derived quantities (container.derived) are then computed from the jackknife samples by calling each derived entry's compute function with the jackknife samples, T, and N, and merging the results into a single named tuple; this allows derived quantities (e.g. connected correlations, susceptibilities) to correctly propagate errors from one or more primary observables via jackknife resampling.

Arguments

  • container: A MeasurementContainer holding per-bin data for each observable (container.data) and a list of derived-quantity specifications (container.derived), each with a compute(jk, T, N) function.
  • T: Temperature, passed through to each derived quantity's compute.
  • N: System size (or other size parameter), passed through to each derived quantity's compute.

Returns

A named tuple (primary = ..., derived = ..., autocorrelation = ...):

  • primary: Dict mapping observable name to its (average, error) pair.
  • derived: Named tuple merging the results of every derived quantity's compute call.
  • autocorrelation: Dict mapping each observable or diagnostic whose time series was recorded (see the time_series keyword of MeasurementContainer; by default the scalar ones) to an AutocorrelationResult for its per-measurement time series (see autocorrelation). Times are in units of measurements, i.e. n_unmeasured + 1 sweeps. The binned error bars in primary/derived are reliable only when bin_size is large compared with tau; as a rule of thumb keep bin_size >= 10 tau.

Autocorrelation

UnitCellMC.AutocorrelationResult — Type
AutocorrelationResult

Result of an autocorrelation analysis of one observable's Monte Carlo time series.

All times are in units of the sampling interval of the series. For the time series recorded by measure! that is one measurement, i.e. n_unmeasured + 1 sweeps (see SimulationParameters); for a pilot run with n_unmeasured = 0 (as in autotune_binning) it is one sweep.

Fields

  • tau::Float64: Integrated autocorrelation time τ_int = 1/2 + Σ_{k=1}^{K} ρ(k), with K chosen by self-consistent windowing. With this convention uncorrelated samples have τ_int = 1/2 and the variance of the sample mean is 2 τ_int σ² / n. Finite when status is :resolved or :anticorrelated, NaN otherwise.
  • tau_err::Float64: Statistical error of tau from the Madras–Sokal formula max(τ_int, 1/2) √(2(2K + 1)/n).
  • acf::Vector{Float64}: Normalized autocorrelation function ρ(k) for k = lags, with ρ(0) = 1. It is computed only up to the window K (or up to the maximum lag when unresolved), not over the whole series.
  • lags::Vector{Int}: Lags 0, 1, … corresponding to acf.
  • n::Int: Number of samples in the series (summed over all chains).
  • window::Int: The self-consistent window K (0 unless resolved).
  • status::Symbol: One of
    • :resolved: tau is a valid estimate;
    • :anticorrelated: tau is significantly below 1/2 (tau + 2 tau_err < 1/2), i.e. successive samples are anticorrelated. This happens e.g. for the signed magnetization under cluster updates, which flip the sign of a large cluster every step. The true value lies in (0, 1/2) but the windowed estimate is unreliable (it may even be negative); naive or binned error bars are then conservative, so for binning purposes such an observable behaves like uncorrelated data;
    • :unresolved: the window condition was never met within the maximum lag, i.e. the series is too short compared to its autocorrelation time. acf then holds the computed lags, and 0.5 + sum(acf[2:end]) is a lower-bound estimate of tau;
    • :constant: the series never changes (e.g. the energy of a frozen configuration), so there are no fluctuations to correlate;
    • :insufficient_data: fewer than two samples;
    • :unsupported: the element type cannot be analyzed.

For vector-valued observables (e.g. a correlation function), every non-constant component is analyzed separately and the result for the slowest component is returned: an unresolved component takes precedence, otherwise the component with the largest tau.

UnitCellMC.autocorrelation — Function
autocorrelation(series; max_lag = nothing, window = 6.0, chain_lengths = nothing)

Estimate the integrated autocorrelation time of one observable's time series with Sokal's self-consistent window: τ_int(K) = 1/2 + Σ_{k=1}^{K} ρ(k) is accumulated lag by lag and the sum stops at the first K with K ≥ window × τ_int(K). The default window = 6 is appropriate for roughly exponential decay; use a larger value for slowly decaying tails.

series may be scalar (AbstractVector{<:Real}) or vector-valued (AbstractVector{<:AbstractVector{<:Real}}, e.g. a correlation function sampled at several displacements). Vector-valued series are analyzed per component and the slowest non-constant component is reported (see AutocorrelationResult). Complex vector-valued series (e.g. the structure factor) are analyzed with real and imaginary parts as separate components.

Keywords

  • max_lag: Largest lag considered. Defaults to one tenth of the shortest chain; if the window condition is not met by then the result is :unresolved.
  • window: Window constant c in K ≥ c τ_int(K).
  • chain_lengths: Lengths of independent chains concatenated in series (e.g. several runs merged by merge_containers); lagged products never straddle two chains.

A constant series returns a :constant result rather than throwing.

Returns

An AutocorrelationResult.

source
UnitCellMC.autocorrelation_function — Function
autocorrelation_function(x; max_lag = length(x) ÷ 2, chain_lengths = nothing)

Compute the normalized autocorrelation function of a scalar time series,

ρ(k) = Σ_i (x[i] - x̄)(x[i + k] - x̄) / Σ_i (x[i] - x̄)²,   ρ(0) = 1,

using the standard (biased, 1/n-normalized) estimator, which has lower variance than the 1/(n - k) form and is the usual choice for windowed estimates of the integrated autocorrelation time.

If x is the concatenation of several independent Markov chains, pass their lengths in chain_lengths: lagged products are then only formed within each chain (the mean x̄ is still the global mean).

Returns

(lags, acf) with lags = 0:max_lag and acf[k + 1] = ρ(k).

Throws

ArgumentError if x has fewer than two samples or is constant, or if chain_lengths is inconsistent with x.

UnitCellMC.tau_lower_bound — Function
tau_lower_bound(result::AutocorrelationResult)

Return the integrated autocorrelation time accumulated up to the largest lag that was computed. For a :resolved result this is result.tau; for an :unresolved result it is a lower-bound estimate (the true tau is larger than what the series could resolve); an :anticorrelated result returns 1/2, the value for uncorrelated samples, which is an upper bound for it. Returns NaN for any other status.

UnitCellMC.recommended_binning — Function
recommended_binning(tau; bin_factor = 10, n_unmeasured = nothing)

Turn an integrated autocorrelation time tau, measured in sweeps (i.e. from a series sampled every sweep, as produced by autotune_binning), into a suggested (bin_size, n_unmeasured).

  • n_unmeasured: if not given, measurements are spaced s = max(1, round(tau)) sweeps apart, i.e. n_unmeasured = s - 1. Closer spacing would add little information per measurement, wider spacing would discard it. Pass n_unmeasured explicitly to keep a spacing of your choice (e.g. 0 when measurements are cheap).
  • bin_size: the number of measurements per bin, chosen so that each bin spans bin_factor integrated autocorrelation times in units of measurements: bin_size = ceil(bin_factor × τ_meas), where τ_meas = 1/2 + (tau - 1/2)/s is an upper bound on the integrated time of the thinned series (valid whenever the autocorrelation function is non-increasing; it tends to 1/2 once measurements are effectively independent). Bins spanning many τ_meas are nearly independent, so the binned/jackknife errors are reliable; the residual relative underestimate of the variance is of order τ_meas / bin_size.

tau below 1/2 (anticorrelation) is treated as 1/2.

Returns

A named tuple (bin_size = ..., n_unmeasured = ...). Choose the production n_measurements = bin_size × n_bins for the desired number of bins.

Throws

ArgumentError if tau is not finite and positive (an unresolved NaN autocorrelation time means the pilot run was too short; there is no safe default), or if bin_factor is not positive.

UnitCellMC.MeasurementContainer — Type
MeasurementContainer{T, S, Ts}

Accumulates binned Monte Carlo measurements and holds the observable specifications needed to analyze them.

Raw measurements are accumulated into bin_sums as they're taken and flushed into data once every bin_size measurements. bin_count tracks the measurements accumulated in the current bin (see the accumulation/flushing functions that operate on this container elsewhere in the codebase).

Fields

  • data::T: Per-observable completed bin values (e.g. a NamedTuple mapping observable name to a vector of per-bin averages), accumulated by measure! and consumed by analyze.
  • bin_sums::S: Per-observable running sums for the bin currently being accumulated, reset each time a bin is flushed into data.
  • time_series::Ts: Per-observable unbinned history of every measurement, kept for autocorrelation analysis in analyze. Successive entries are n_unmeasured + 1 sweeps apart. Only the observables selected by the constructor's time_series keyword are recorded (by default the scalar ones), so its keys are a subset of those of data.
  • chain_lengths::Vector{Int}: Lengths of the independent Markov chains concatenated in time_series when containers are combined with merge_containers; empty for a single run.
  • bin_count::Int: Number of measurements accumulated in the current bin; reset to 0 when the bin is flushed into data.
  • bin_size::Int: Number of measurements per bin (n_measurements ÷ n_bins).
  • observables::Vector{Observable}: The raw observables being measured.
  • derived::Vector{DerivedObservable}: The derived quantities to compute from the raw observables once binning is complete.
  • diagnostics::Vector{Symbol}: Names of per-sweep algorithm diagnostics accumulated alongside the raw observables.

Construct with MeasurementContainer(model, geometry, n_measurements, n_bins; measurements).

UnitCellMC.correlation_instantaneous — Function
correlation_instantaneous(model, state, disp)

Compute one instantaneous sample of the correlation function for state, one value per displacement class in disp.

For each displacement class r, averages operator_product(model, ...) over every valid starting site (site i, orbital oi) paired with its partner at the class's displacement (site j, orbital oj), wrapping coordinates with periodic boundary conditions where applicable, and dividing by the class's site count for a proper average.

Arguments

  • model: The model providing operator_product.
  • state: The current configuration, read via local_operator.
  • disp: Displacement class data as returned by build_displacement_classes, giving unit_cell, lattice, displacements, orbitals, valid_ranges, and counts.

Returns

A Vector{Float64} of length length(disp.displacements), one correlation value per displacement class, in the same order as disp.

UnitCellMC.correlation_entry — Function
correlation_entry(model, geometry)

Build the raw and derived observable entries needed to measure the correlation function of model on geometry.

Precomputes the displacement classes once (via build_displacement_classes) and wraps them in an Observable named :correlation (sampled per measurement with correlation_instantaneous) and a DerivedObservable that computes the connected correlation via jackknife resampling (see jackknife_stats). For XY it subtracts ⟨m_x⟩² + ⟨m_y⟩²; for other models it subtracts ⟨m⟩². The result also includes the CorrelationClass list labeling each entry.

Arguments

  • model: The model to measure correlations for.
  • geometry: The lattice geometry.

Returns

An (observable, derived) tuple:

  • observable: An Observable for :correlation, sampling a Vector{Float64} (one value per displacement class) each measurement.
  • derived: A DerivedObservable computing :correlation_connected, :correlation_connected_err, and :correlation_classes from :correlation and the Cartesian magnetization components (their declared depends_on).

Structure factor

UnitCellMC.StructureFactorClass — Type
StructureFactorClass{D,T}

Labels one entry of the structure factor: the momentum k and the orbital pair (orbital_i, orbital_j) of $S_{ab}(\mathbf{k})$.

Fields

  • momentum_index::NTuple{D,Int}: Integer location n of the momentum on the finite-lattice grid, k = Σ_d (n[d] / L[d]) b_d with b_d the reciprocal lattice vectors. Along open (non-periodic) dimensions only n[d] = 0 is used, matching LatticeUtilities.calc_k_points.
  • momentum::NTuple{D,T}: The Cartesian momentum k.
  • orbitals::Tuple{Int,Int}: The (orbital_i, orbital_j) pair.

See also build_momentum_classes and CorrelationClass, its real-space counterpart.

source
UnitCellMC.build_momentum_classes — Function
build_momentum_classes(geometry::Geometry{D}) where D

Precompute, once per geometry, the momentum grid and lookup tables needed by structure_factor_instantaneous.

The momentum grid has L[d] points along each periodic dimension and a single point (k_d = 0) along each open dimension. Entries are ordered by orbital pair (oi, oj) (with oj varying fastest) and, within each pair, by momentum in column-major order (first dimension fastest), the same ordering as build_displacement_classes.

Arguments

  • geometry: A Geometry{D} providing the unit cell and lattice.

Returns

A named tuple with fields

  • classes::Vector{StructureFactorClass}: Label of each structure-factor entry, in output order.
  • sites::Vector{Array{Int,D}}: For each orbital, the site index of that orbital in the unit cell at location l stored at sites[o][(l .+ 1)...].
  • phases::NTuple{D,Matrix{ComplexF64}}: Per-dimension Fourier matrices, phases[d][n + 1, l + 1] = exp(-2πi n l / L[d]) (a single row of ones along open dimensions).
  • n_cells::Int: Number of unit cells, used for normalization.
  • n_orbitals::Int: Number of orbitals per unit cell.
  • n_momenta::Int: Number of momenta on the grid.

UnitCellMC.fourier_transform_dim — Function
fourier_transform_dim(A, W, d)

Contract dimension d of the array A with the matrix W, B[…, n, …] = Σ_l W[n, l] A[…, l, …]. Applying this along every dimension with the matrices from build_momentum_classes gives a D-dimensional discrete Fourier transform in O(N Σ_d L[d]) operations without an FFT dependency.

UnitCellMC.structure_factor_instantaneous — Function
structure_factor_instantaneous(model, state, momenta)

Compute one instantaneous sample of the orbital-resolved structure factor

\[S_{ab}(\mathbf{k}) = \frac{1}{N_c} \sum_\alpha \overline{\rho^\alpha_a(\mathbf{k})}\, \rho^\alpha_b(\mathbf{k}), \qquad \rho^\alpha_a(\mathbf{k}) = \sum_{\mathbf{R}} S^\alpha_{\mathbf{R},a}\, e^{-i\mathbf{k}\cdot\mathbf{R}},\]

where R runs over the N_c unit cells, a, b are orbitals, and S^α_{R,a} are the operator_components of the local operator on that site. On a periodic lattice this equals Σ_Δ C_ab(Δ) exp(-i k·Δ), the Fourier transform of the correlation function from correlation_instantaneous. Phases use unit-cell positions only; the orbital basis offsets are not included.

Arguments

  • model: The model providing operator_components.
  • state: The current configuration, read via local_operator.
  • momenta: Momentum data from build_momentum_classes.

Returns

A Vector{ComplexF64} with one entry per class in momenta.classes, in the same order. Diagonal orbital entries (a == b) are real and non-negative; S_ba(k) == conj(S_ab(k)).

source
UnitCellMC.structure_factor_entry — Function
structure_factor_entry(model, geometry)

Build the optional structure-factor observable for a model.

Precomputes the momentum grid once (via build_momentum_classes) and wraps it in a vector-valued, complex Observable named :structure_factor, sampled per measurement with structure_factor_instantaneous: the orbital-resolved $S_{ab}(\mathbf{k})$ for every orbital pair and every momentum on the finite-lattice grid. A DerivedObservable passes the StructureFactorClass labels through to the analysis results as :structure_factor_classes.

The measurement works for any model implementing n_operator_components and operator_components; no model-specific code is needed here.

Arguments

  • model: The model being measured.
  • geometry: The lattice geometry.

Returns

An (obs, der) tuple:

  • obs::Vector{Observable}: The :structure_factor observable, sampling a Vector{ComplexF64} each measurement. Its analyze error is complex, holding the standard errors of the real and imaginary parts.
  • der::Vector{DerivedObservable}: Produces :structure_factor_classes.

Throws

ArgumentError if model does not implement n_operator_components.

UnitCellMC.measure! — Function
measure!(measurements::MeasurementContainer, state; diagnostics)

Take one measurement of state and accumulate it into measurements, flushing a completed bin into data once bin_size measurements have been accumulated.

Each observable in measurements.observables is evaluated on state via its value function, and the supplied algorithm diagnostic values are added to the same named tuple. The results are added elementwise into measurements.bin_sums. Once measurements.bin_count reaches measurements.bin_size, the accumulated sums are averaged (dividing by bin_size) and pushed onto the corresponding vector in measurements.data, after which bin_sums is reset to zero (via each observable's zero()) and bin_count returns to 0 to begin accumulating the next bin.

Arguments

  • measurements: The MeasurementContainer to update in place.
  • state: The current configuration to measure, passed to each observable's value function.
  • diagnostics: A named tuple of per-sweep algorithm statistics. Its names must match the diagnostics requested when the container was constructed.

Returns

nothing. measurements is mutated in place.

UnitCellMC.derived_observables — Function
derived_observables(::IsingModel, geometry)

Return the always-on derived quantities computed for every IsingModel simulation: specific heat and magnetic susceptibility, obtained via fluctuation formulas from the raw energy/magnetization observables.

Specific heat is computed as N * (⟨e²⟩ - ⟨e⟩²) / T² and susceptibility as N * (⟨m²⟩ - ⟨m⟩²) / T, using jackknife samples of the per-site energy and magnetization observables from observables (each DerivedObservable declares its dependency on the corresponding :energy/:magnetization pair, so validate_dependencies can confirm they're being measured, and errors are obtained automatically via jackknife_stats).

Arguments

  • model: The IsingModel being measured (unused beyond dispatch).
  • geometry: The lattice geometry (unused directly; included for a consistent (model, geometry) dispatch signature).

Returns

A Vector{DerivedObservable} with two entries: (:specific_heat, :specific_heat_err) depending on (:energy, :energy_squared), and (:susceptibility, :susceptibility_err) depending on (:magnetization, :magnetization_squared).
