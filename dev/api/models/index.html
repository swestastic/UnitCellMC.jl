UnitCellMC.IsingModel — Type
IsingModel(J, h)

An Ising model with bond strengths J and external field h.

Arguments

  • J: Bond strengths, one value per bond template. Its length is checked against geometry.bonds by initialize_state, since the constructor does not receive a geometry.
  • h: External magnetic field, one value per site in the unit cell.

UnitCellMC.XYModel — Type
XYModel{T<:Real} <: AbstractModel

The classical XY model with bond strengths J (one value per bond template) and external fields h (one value per site in the unit cell). The field points along the x direction, so its contribution is -h[i] * cos(angle[i]).

source
UnitCellMC.ClockModel — Type
ClockModel{T<:Real} <: AbstractModel

The q-state clock model: planar spins restricted to the q angles θ = 2π n / q, n ∈ 0:q-1, with Hamiltonian

H = -Σ_⟨ij⟩ J_ij cos(θ_i - θ_j) - Σ_i h_i cos(θ_i)

with bond strengths J (one value per bond template) and external fields h (one value per site in the unit cell). As for the XYModel, the field points along the x direction. q = 2 is the Ising model and q → ∞ approaches the XY model.

Fields

  • q::Int: Number of clock states.
  • J::Vector{T}: Bond strengths, one per bond template.
  • h::Vector{T}: External fields, one per site in the unit cell.
  • cosines::Vector{Float64}: Lookup table, cosines[n + 1] = cos(2π n / q).
  • sines::Vector{Float64}: Lookup table, sines[n + 1] = sin(2π n / q).

Construct with ClockModel(q, J, h).

UnitCellMC.clock_cos — Function
clock_cos(model::ClockModel, n)
clock_sin(model::ClockModel, n)

Return cos(2π n / q) (resp. sin(2π n / q)) from the lookup tables of model. n may be any integer; it is reduced modulo q, so differences of clock indices can be passed directly, e.g. clock_cos(model, n_i - n_j) for the bond term cos(θ_i - θ_j).

UnitCellMC.ClockUpdate — Type
ClockUpdate

A proposed single-site clock move: change the clock index at site to new_value. The proposal carries the magnetization change of the move, computed by propose from the model's lookup tables, so that apply_update! can keep the cached totals exact without access to the model.

Fields

  • site::Int: Index of the site to update.
  • new_value::Int: The proposed clock index, in 0:q-1.
  • magnetization_x_change::Float64: cos(θ_new) - cos(θ_old).
  • magnetization_y_change::Float64: sin(θ_new) - sin(θ_old).

UnitCellMC.ClockClusterContext — Type
ClockClusterContext

Per-update state of a clock-model cluster move (Wolff or Swendsen-Wang).

The move reflects spins across one of the q mirror lines of the clock, n ↦ mod(mirror - n, q), which is the XY reflection θ ↦ 2φ + π - θ about the axis φ = π mirror / q - π/2; it maps clock states onto clock states.

Fields

  • mirror::Int: Mirror index in 0:q-1.
  • projections::Vector{Float64}: projections[n + 1] = cos(2π n / q - φ), the component of clock state n along the reflection axis.
  • ghost_projection::Float64: cos(φ), the axis component of the +x ghost spin (the -x ghost has -cos(φ)).
  • ghost_attached::Bool: Whether a Wolff cluster has bonded to a ghost spin, in which case it is not reflected.

UnitCellMC.n_operator_components — Function
n_operator_components(model::AbstractModel)

Return the number of real components of the local operator of model, i.e. the length of the tuple returned by operator_components.

This is the model hook that enables the :structure_factor measurement (see structure_factor_entry). A new model supports the structure factor by implementing this method together with operator_components; nothing else in the measurement code needs to change. For example, a Heisenberg model would return 3, a q-state clock model 2.

Throws

ArgumentError for models that do not implement the hook.

source
UnitCellMC.operator_components — Function
operator_components(model::AbstractModel, value)

Return the real components of the local operator value (as returned by local_operator) as a tuple of length n_operator_components(model).

The components must reproduce the model's two-body product,

operator_product(model, a, b) ≈ sum(operator_components(model, a) .* operator_components(model, b))

so that the structure factor is exactly the Fourier transform of the correlation function measured by correlation_instantaneous. For an Ising spin s this is (s,); for an XY angle θ it is (cos θ, sin θ); for a clock index n it is (cos(2πn/q), sin(2πn/q)).

Throws

ArgumentError for models that do not implement the hook.

UnitCellMC.energy_difference — Function
energy_difference(model, geometry, state, proposal)

Compute the change in total energy ΔE that would result from changing the spin at proposal.site to proposal.new_value, given the couplings and field in model.

Arguments

  • model: The IsingModel providing bond strengths and field h.
  • geometry: Lattice geometry giving each site's neighbors and bonds.
  • state: Current spin configuration.
  • proposal: A SpinUpdate describing the trial move.

Returns

The energy difference ΔE between the proposed and current configurations. For current spin s, proposed spin s_new, and local field H = h + sum(J * neighbor_spin), this is (s - s_new) * H.

UnitCellMC.apply_cluster! — Function
apply_cluster!(model, geometry, state, cluster)

Flip a Wolff cluster and update the cached Ising observables incrementally. Only bonds crossing the cluster boundary change energy: with pre-flip spins, a boundary bond (i, j) with i in the cluster contributes ΔE = 2 * J * spins[i] * spins[j], and each flipped site contributes a field term ΔE = 2 * h * spins[i] and ΔM = -2 * spins[i].

source
apply_cluster!(model, geometry, state, cluster, reflection_axis)

Reflect a Wolff cluster about reflection_axis and update the cached XY observables incrementally. With p_i = cos(angles[i] - reflection_axis) evaluated pre-reflection, a boundary bond (i, j) with i in the cluster contributes ΔE = 2 * J * p_i * p_j (via cos(2φ - θ_i - θ_j) + cos(θ_i - θ_j) = 2 * p_i * p_j), and each reflected site contributes ΔE = 2 * h * cos(φ) * p_i, ΔM_x = -2 * cos(φ) * p_i, and ΔM_y = -2 * sin(φ) * p_i.

source

UnitCellMC.apply_clusters! — Function
apply_clusters!(rng, model, geometry, state, clusters)

Randomly orient each Swendsen-Wang cluster (coin flips drawn from rng) and update the cached Ising observables incrementally. A bond only changes energy when exactly one of its endpoints sits in a flipped cluster, so the energy update touches only bonds incident to flipped sites rather than resumming the whole lattice.

source
apply_clusters!(rng, model, geometry, state, clusters, reflection_axis)

A bond only changes energy when exactly one of its endpoints sits in a reflected cluster, so the energy update touches only bonds incident to reflected sites rather than resumming the whole lattice.

UnitCellMC._reflect_clock_sites! — Function
_reflect_clock_sites!(model, geometry, state, sites, reflected, mirror)

Apply the clock reflection n ↦ mod(mirror - n, q) to every site in sites and accumulate the exact energy and magnetization change from the lookup tables. reflected[i] must be true exactly for the sites in sites.

Bonds with both endpoints reflected keep their energy (cos(θ_i - θ_j) is invariant under a common reflection), so only bonds crossing the boundary of the reflected set are visited; their far endpoint is never mutated, so pre- and post-reflection energies are evaluated directly as -J (cos(θ'_i - θ_j) - cos(θ_i - θ_j)).
