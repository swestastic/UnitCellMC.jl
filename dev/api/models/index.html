UnitCellMC.AbstractModel — Type
AbstractModel{T<:Real}

Abstract supertype for the spin models simulated by this package (IsingModel, XYModel, ClockModel).

Coupling layout contract

A model provides one bond coupling per bond template of the Geometry and one external-field value per unit-cell orbital, exposed through the couplings and fields accessors (by default the model's J and h fields). The checked bond_strength/field_strength lookups, the from-scratch energy sums, and every hot inner loop read couplings and fields through these accessors, so a model with a different storage layout overrides exactly these two functions (plus validate_model_geometry for its checks) instead of hunting down every read site.

A model also declares its state type (state_type) and implements the single-site update contract (propose, energy_difference; apply_update! comes with the state), its observables (observables, derived_observables), and optionally the cluster-update hooks and binder_denominator.

UnitCellMC.IsingModel — Type
IsingModel(J, h)

An Ising model with bond strengths J and external field h.

Arguments

  • J: Bond strengths, one value per bond template. Its length is checked against geometry.bonds by initialize_state, since the constructor does not receive a geometry.
  • h: External magnetic field, one value per site in the unit cell.

UnitCellMC.XYModel — Type
XYModel{T<:Real} <: AbstractModel

The classical XY model with bond strengths J (one value per bond template) and external fields h (one value per site in the unit cell). The field points along the x direction, so its contribution is -h[i] * cos(angle[i]).

UnitCellMC.ClockModel — Type
ClockModel{T<:Real} <: AbstractModel

The q-state clock model: planar spins restricted to the q angles θ = 2π n / q, n ∈ 0:q-1, with Hamiltonian

H = -Σ_⟨ij⟩ J_ij cos(θ_i - θ_j) - Σ_i h_i cos(θ_i)

with bond strengths J (one value per bond template) and external fields h (one value per site in the unit cell). As for the XYModel, the field points along the x direction. q = 2 is the Ising model and q → ∞ approaches the XY model.

Fields

  • q::Int: Number of clock states.
  • J::Vector{T}: Bond strengths, one per bond template.
  • h::Vector{T}: External fields, one per site in the unit cell.
  • cosines::Vector{Float64}: Lookup table, cosines[n + 1] = cos(2π n / q).
  • sines::Vector{Float64}: Lookup table, sines[n + 1] = sin(2π n / q).

Construct with ClockModel(q, J, h).

UnitCellMC.clock_cos — Function
clock_cos(model::ClockModel, n)
clock_sin(model::ClockModel, n)

Return cos(2π n / q) (resp. sin(2π n / q)) from the lookup tables of model. n may be any integer; it is reduced modulo q, so differences of clock indices can be passed directly, e.g. clock_cos(model, n_i - n_j) for the bond term cos(θ_i - θ_j).

UnitCellMC.ClockClusterContext — Type
ClockClusterContext

Per-update state of a clock-model cluster move (Wolff or Swendsen-Wang).

The move reflects spins across one of the q mirror lines of the clock, n ↦ mod(mirror - n, q), which is the XY reflection θ ↦ 2φ + π - θ about the axis φ = π mirror / q - π/2; it maps clock states onto clock states.

Fields

  • mirror::Int: Mirror index in 0:q-1.
  • projections::Vector{Float64}: projections[n + 1] = cos(2π n / q - φ), the component of clock state n along the reflection axis.
  • ghost_projection::Float64: cos(φ), the axis component of the +x ghost spin (the -x ghost has -cos(φ)).
  • ghost_attached::Bool: Whether a Wolff cluster has bonded to a ghost spin, in which case it is not reflected.

UnitCellMC.couplings — Function
couplings(model)

Return the model's bond couplings, one per bond template of the Geometry (see the layout contract under AbstractModel). The default is model.J; a model storing couplings differently overrides this accessor rather than every read site.

UnitCellMC.bond_strength — Function
bond_strength(model, geometry, bond_id)

Return the coupling strength J for the bond identified by bond_id, looked up via the bond's template in geometry and the model's couplings.

This is the checked convenience lookup, intended for setup and analysis code. Performance-critical inner loops should instead iterate a site's NeighborInfo and index couplings(model)[template] directly: the per-site templates vector is parallel to neighbors, so neither the bounds check here nor the bond_id_to_template indirection is needed there.

Arguments

  • model: The model supplying one coupling per bond template.
  • geometry: The lattice geometry mapping bond ids to templates.
  • bond_id: Index of the bond to look up.

Throws

ArgumentError if bond_id is out of bounds for geometry.bond_id_to_template.

UnitCellMC.validate_model_geometry — Function
validate_model_geometry(model, geometry)

Validate the compatibility between a model's coupling/field data and the lattice geometry. The generic method enforces the package-wide layout conventions for models that carry them: a bond-coupling vector model.J must have one entry per bond template in geometry.bonds, and a field vector model.h must have one entry per unit-cell orbital. (The template ids in geometry.bond_id_to_template are valid by construction, so only lengths need checking.) Models with J and h fields (IsingModel, XYModel, ClockModel) need no method of their own.

Models that store couplings or fields differently override couplings/fields and should extend this method with their own checks.

Throws

ArgumentError naming the mismatched lengths or out-of-bounds template id.

Returns

nothing.

UnitCellMC.binder_denominator — Function
binder_denominator(model)

Return the denominator of the fourth-order Binder cumulant, 1 - ⟨m⁴⟩ / (binder_denominator * ⟨m²⟩²), for model's order parameter: 3 for a one-component (Ising) order parameter, 2 for a two-component (XY, or clock with q >= 3) one — the high-temperature Gaussian cumulant ratio. Required by the :binder_cumulant optional measurement.

Throws

ArgumentError for models without their own method; define binder_denominator(::MyModel) to enable :binder_cumulant.

UnitCellMC.clock_angle_order — Function
clock_angle_order(model::ClockModel, state::ClockState)

Return the instantaneous angular order parameter cos(q φ_M) of state, where φ_M = atan(M_y, M_x) is the direction of the total magnetization.

The magnetization is resummed from state.spins (O(N)) rather than read from the running totals. On small lattices M = 0 is a common configuration, and there the running totals hold only rounding residue whose direction is meaningless and grows with run length. A fresh sum is accurate to about N * eps(), so |M| <= √eps() is treated as zero, for which the direction is undefined and 0.0 is returned.

UnitCellMC.state_type — Function
state_type(model)

Return the AbstractState subtype that model simulates: the type that initialize_state constructs for it, and the type that step!, measurements, and the simulation drivers expect to receive (see validate_model_state).

Each model defines its own method (e.g. state_type(::IsingModel) = IsingState); this fallback throws so that a model without one fails loudly, like the initialize_state fallback.

Throws

ArgumentError if model does not define its own state_type method. To support a custom model, define state_type(::MyModel) = MyState.

UnitCellMC.magnetization_value — Function
magnetization_value(state)

Return the scalar magnetization represented by state: the stored total magnetization for an IsingState, and the magnitude hypot(magnetization_x, magnetization_y) of the two components for an XYState or ClockState. UnitCellMC.n_operator_components — Function
n_operator_components(model::AbstractModel)

Return the number of real components of the local operator of model, i.e. the length of the tuple returned by operator_components.

This is the model hook that enables the :structure_factor measurement (see structure_factor_entry). A new model supports the structure factor by implementing this method together with operator_components; nothing else in the measurement code needs to change. For example, a Heisenberg model would return 3, a q-state clock model 2.

Throws

ArgumentError for models that do not implement the hook.

source
UnitCellMC.operator_components — Function
operator_components(model::AbstractModel, value)

Return the real components of the local operator value (as returned by local_operator) as a tuple of length n_operator_components(model).

The components must reproduce the model's two-body product,

operator_product(model, a, b) ≈ sum(operator_components(model, a) .* operator_components(model, b))

so that the structure factor is exactly the Fourier transform of the correlation function measured by correlation_instantaneous. For an Ising spin s this is (s,); for an XY angle θ it is (cos θ, sin θ); for a clock index n it is (cos(2πn/q), sin(2πn/q)).

Throws

ArgumentError for models that do not implement the hook.

UnitCellMC.energy_difference — Function
energy_difference(model, geometry, state, proposal)

Compute the change in total energy ΔE that would result from changing the spin at proposal.site to proposal.new_value, given the couplings and field in model.

Arguments

  • model: The IsingModel providing bond strengths and field h.
  • geometry: Lattice geometry giving each site's neighbors and bonds.
  • state: Current spin configuration.
  • proposal: A SpinUpdate describing the trial move.

Returns

The energy difference ΔE between the proposed and current configurations. For current spin s, proposed spin s_new, and local field H = h + sum(J * neighbor_spin), this is (s - s_new) * H.

UnitCellMC.validate_cluster_model — Function
validate_cluster_model(model, geometry, state, T)

Check that model can be updated by the cluster algorithms (WolffAlgorithm, SwendsenWangAlgorithm), called once at the start of every cluster step!.

The default enforces the cluster updates' core requirement — non-negative (ferromagnetic) couplings, so the bond-activation probabilities stay in [0, 1] — for models with the default coupling layout (see couplings); a model without a J field passes. Models with extra structure extend this method with their own checks.

Throws

ArgumentError if any coupling is negative.

Returns

nothing.

UnitCellMC.apply_cluster! — Function
apply_cluster!(model, geometry, state, cluster)

Flip a Wolff cluster and update the cached Ising observables incrementally. Only bonds crossing the cluster boundary change energy: with pre-flip spins, a boundary bond (i, j) with i in the cluster contributes ΔE = 2 * J * spins[i] * spins[j], and each flipped site contributes a field term ΔE = 2 * h * spins[i] and ΔM = -2 * spins[i].

This explicit form allocates a membership mask per call and serves as the readable reference implementation (exercised by the tests); the Wolff driver passes down the mask it already built.

source
apply_cluster!(model, geometry, state, cluster, reflection_axis)

Reflect a Wolff cluster about reflection_axis and update the cached XY observables incrementally. With p_i = cos(angles[i] - reflection_axis) evaluated pre-reflection, a boundary bond (i, j) with i in the cluster contributes ΔE = 2 * J * p_i * p_j (via cos(2φ - θ_i - θ_j) + cos(θ_i - θ_j) = 2 * p_i * p_j), and each reflected site contributes ΔE = 2 * h * cos(φ) * p_i, ΔM_x = -2 * cos(φ) * p_i, and ΔM_y = -2 * sin(φ) * p_i. This explicit form allocates a membership mask per call and is the readable reference implementation exercised by the tests; the Wolff driver passes down the mask it already built.

source
apply_clusters!(rng, model, geometry, state, workspace, context)

Randomly orient each Swendsen-Wang cluster and update the cached Ising observables incrementally via _flip_ising_clusters!. The orientation decisions are drawn by draw_cluster_flips! — one coin flip per cluster, in the first-encounter order of workspace.roots, with ghost-attached clusters never flipped — and recorded per root-id label in workspace.flip.

context is unused for the Ising model: ghost attachment is read from the labels alone.

A bond only changes energy when exactly one of its endpoints sits in a flipped cluster, so the energy update touches only bonds incident to flipped sites rather than resumming the whole lattice.

UnitCellMC._reflect_xy_clusters! — Function
_reflect_xy_clusters!(model, geometry, state, labels, flip, reflection_axis)

Reflect every lattice site whose cluster label is marked in flip, accumulating the exact energy and magnetization change. labels[i] is the union-find root of site i (see step! with SwendsenWangAlgorithm) and doubles as the site→cluster map: a bond incident to a reflected site is internal (both endpoints reflect, no change) when flip[labels[neighbor]] is true, external (never visited) when neither endpoint reflects, and crossing (counted once, from the reflected side, with pre-reflection angles) otherwise.

UnitCellMC._reflect_clock_sites! — Function
_reflect_clock_sites!(model, geometry, state, sites, reflected, mirror)

Apply the clock reflection n ↦ mod(mirror - n, q) to every site in sites and accumulate the exact energy and magnetization change from the lookup tables. reflected[i] must be true exactly for the sites in sites.

Bonds with both endpoints reflected keep their energy (cos(θ_i - θ_j) is invariant under a common reflection), so only bonds crossing the boundary of the reflected set are visited; their far endpoint is never mutated, so pre- and post-reflection energies are evaluated directly as -J (cos(θ'_i - θ_j) - cos(θ_i - θ_j)).

source
UnitCellMC._reflect_clock_clusters! — Function
_reflect_clock_clusters!(model, geometry, state, labels, flip, mirror)

Reflect every lattice site whose cluster label is marked in flip across clock mirror mirror (n -> mod(mirror - n, q)), accumulating the exact energy and magnetization change from the lookup tables. labels[i] is the union-find root of site i (see step! with SwendsenWangAlgorithm) and doubles as the site-to-cluster map: a bond incident to a reflected site is internal (both endpoints reflect, and reflection preserves cos(θ_i - θ_j)) when flip[labels[neighbor]] is true, external (never visited) when neither endpoint reflects, and crossing (counted once, from the reflected side, with pre-reflection indices) otherwise. Sites lying on the mirror (new == old) do not move, so their incident bonds are unchanged and are skipped together with the site itself.
