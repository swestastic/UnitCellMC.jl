UnitCellMC.results_dirname — Function
results_dirname(model, algorithm, L, T; root = "results")

Construct the output directory path for a single-temperature run, encoding the model type, algorithm type, system size L, and temperature T into the directory name.

Arguments

  • model: The model instance being simulated (only its type name is used).
  • algorithm: The algorithm instance being used (only its type name is used).
  • L: System size, joined component-wise with "x" (e.g. (4, 4) → "4x4").
  • T: Temperature, rounded to 6 digits for the directory name.
  • root: Base directory under which the run directory is created.

Returns

The path root/ModelName_AlgorithmName_LWxH_tempT, without creating it.

UnitCellMC.measurement_rows — Function
measurement_rows(results)

Flatten the scalar-valued entries of results into parallel vectors of observable names, values, and errors, suitable for building a DataFrame.

Both results.primary (a collection of (average, error) pairs keyed by name) and results.derived (a NamedTuple-like collection of derived quantities, some paired with a *_err sibling) are scanned. Only scalar (Real) entries are included; vector- or struct-valued entries (e.g. :correlation, correlation_classes) are skipped, since those are handled separately by correlation_rows. A derived value with no matching *_err property gets missing for its error. Primary entries are emitted in sorted name order (primary is a Dict, whose iteration order varies between sessions), so the CSV output is deterministic.

Returns

A (names, values, errors) tuple of equal-length vectors:

  • names::Vector{String}: Observable names.
  • values::Vector{Float64}: Observable values.
  • errors::Vector{Union{Float64,Missing}}: Corresponding errors, or missing.

UnitCellMC.correlation_rows — Function
correlation_rows(results)

Build a DataFrame of per-displacement-class correlation data from results, or return nothing if results has no correlation_classes.

Each row corresponds to one displacement class (see build_displacement_classes) and records its displacement components, orbital pair, raw correlation value/error, and connected correlation value/error.

Arguments

  • results: A results object with results.derived.correlation_classes (a vector of class descriptors with displacement and orbitals fields), results.primary[:correlation] (raw correlation (values, errors)), and results.derived.correlation_connected / correlation_connected_err.

Returns

A DataFrame with columns disp_1, ..., disp_D, orbital_i, orbital_j, raw_value, raw_error, connected_value, connected_error, or nothing if results has no correlation data.

UnitCellMC.structure_factor_rows — Function
structure_factor_rows(results)

Build a DataFrame of structure-factor data from results, or return nothing if results has no structure_factor_classes (i.e. the :structure_factor measurement was not requested).

Each row corresponds to one StructureFactorClass: an orbital pair and a momentum on the finite-lattice grid (see build_momentum_classes).

Arguments

  • results: A results object with results.derived.structure_factor_classes and results.primary[:structure_factor] (complex (values, errors), as returned by analyze).

Returns

A DataFrame with columns k_index_1, ..., k_index_D (integer grid location), k_1, ..., k_D (Cartesian momentum), orbital_i, orbital_j, real_value, real_error, imag_value, imag_error, or nothing if results has no structure-factor data.

UnitCellMC.autocorrelation_rows — Function
autocorrelation_rows(results)

Build a DataFrame of integrated autocorrelation times from results.autocorrelation (as produced by analyze), one row per observable sorted by name, or return nothing if results has no autocorrelation data.

Columns: observable, tau, tau_err, window, n_samples, status. tau is in units of measurements (n_unmeasured + 1 sweeps) and is NaN unless status == "resolved"; see AutocorrelationResult.

UnitCellMC.save_results — Function
save_results(model, algorithm, geometry, T, results, parameters;
    root = "results", seed = global_seed())

Save all output for a single-temperature run: create the run directory, write metadata, measurements, correlations (if any), the structure factor (if any), and autocorrelation times (if any).

Combines results_dirname, save_metadata, save_measurements, save_correlations, save_structure_factor, and save_autocorrelation into one call.

Arguments

  • model, algorithm, geometry, T: Identify the run; the system size is read from geometry.lattice.L to name the directory and record the metadata.
  • results: The measurement results to save.
  • parameters: Simulation parameters recorded in the metadata.
  • root: Base directory under which the run directory is created.
  • seed: RNG seed recorded in the metadata (see save_metadata).

Returns

The path to the created run directory.

UnitCellMC.save_sweep_results — Function
save_sweep_results(sweep_results, Ts, model, algorithm, geometry,
                    n_thermalization, n_measurements, n_unmeasured, n_bins;
                    root = "results", seed = global_seed())

Save the combined output of a temperature sweep into a single directory: measurement_results.csv, correlation_results.csv, structure_factor_results.csv, and autocorrelation_results.csv, each spanning all temperatures with a leading temperature column, plus sweep metadata.

sweep_results[i] must correspond to Ts[i]; per-temperature rows are built with measurement_rows, correlation_rows, structure_factor_rows, and autocorrelation_rows and concatenated across all temperatures. Temperatures with no correlation (structure-factor, autocorrelation) data are simply omitted from the corresponding file; if none have such data, that file is not written at all. Autocorrelation times are in units of measurements, i.e. n_unmeasured + 1 sweeps.

Arguments

  • sweep_results: Results for each temperature, same length and order as Ts.
  • Ts: Temperatures included in the sweep.
  • model, algorithm, geometry: Identify the run; the system size is read from geometry.lattice.L to name the directory and record the metadata.
  • n_thermalization, n_measurements, n_unmeasured, n_bins: Sweep simulation parameters, recorded in the metadata.
  • root: Base directory under which the sweep directory is created.
  • seed: RNG seed recorded in the metadata (see save_sweep_metadata).

Throws

ArgumentError if sweep_results and Ts have different lengths.

Returns

The path to the created sweep directory.

UnitCellMC._write_sweep_csv — Function
_write_sweep_csv(dir, filename, rows_fn, Ts, sweep_results)

Build and write one per-temperature output file of a temperature sweep: rows_fn(results) produces each temperature's DataFrame (or nothing when that temperature has no such data), a leading temperature column is added, and the concatenated frame is written to dir/filename. If no temperature produced rows, the file is not written — and a stale file from an earlier run is removed, so the directory never mixes data from different measurements sets.

Returns

nothing.
