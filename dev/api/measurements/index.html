Measurements

UnitCellMC.average_and_error — Function
average_and_error(values::Vector{<:Real})

Compute the bin average and standard error of the mean for a scalar observable's per-bin values.

The error is estimated as sqrt(variance / n_bins), where variance is the sample variance of values (Bessel-corrected, dividing by n_bins - 1).

Arguments

  • values: Per-bin averages for one scalar observable (e.g. energy, magnetization), one entry per bin. Any real element type works (e.g. Float32).

Throws

ArgumentError if fewer than two bins are given.

Returns

A (average, error) tuple.

source
average_and_error(values::Vector{<:Complex})

Complex counterpart of the scalar method, for observables such as ⟨e^{iθ}⟩: the average is complex, and the error is the real standard error sqrt(Σ|x−μ|² / ((n−1) n)) of the magnitude fluctuations.

Throws

ArgumentError if fewer than two bins are given.

Returns

A (average, error) tuple with a complex average and a real error.

average_and_error(values::Vector{<:Vector{<:Real}})

Compute the elementwise bin average and standard error of the mean for a vector-valued observable's per-bin values (e.g. a correlation function evaluated at each displacement).

Each element of values is one bin's vector of per-displacement (or otherwise per-component) values; these are stacked into an n_disp × n_bins matrix and averaged/errored along the bin dimension. Any real element type works (e.g. Float32).

Arguments

  • values: Per-bin value vectors for one vector-valued observable, one vector per bin, all of equal length.

Throws

ArgumentError if fewer than two bins are given.

DimensionMismatch if the per-bin vectors do not all have the same length.

Returns

An (averages, errors) tuple of vectors, each of the same length as the per-bin vectors in values.

average_and_error(values::Vector{<:AbstractArray})

Generic fallback for array-valued observables whose bin values are not plain Float64 vectors or matrices (say Float32 matrices, or another AbstractArray eltype): elementwise bin average and Bessel-corrected standard error of the mean, requiring only Statistics.mean/Statistics.std support from the element type.

This is what lets custom observables with other numeric element types reach analyze without defining their own method; the scalar, vector, and complex-vector methods above take precedence where they apply (in particular complex vector-valued observables keep their per-component error convention).

Throws

ArgumentError if fewer than two bins are given.

Returns

An (averages, errors) tuple of the same array type as the per-bin values.

UnitCellMC.jackknife_samples — Function
jackknife_samples(bin_values::Vector{T}) where T

Compute leave-one-out jackknife samples from per-bin values.

For n = length(bin_values) bins with total total = sum(bin_values), the i-th jackknife sample is (total - bin_values[i]) / (n - 1), i.e. the average of all bins except the i-th.

Arguments

  • bin_values: Per-bin values (scalar or vector-valued, any type supporting sum, subtraction, and elementwise division).

Throws

ArgumentError if fewer than two bins are given.

Returns

A vector of n jackknife samples, one per omitted bin. The element type is determined by the subtraction and division operations.

UnitCellMC.jackknife_stats — Function
jackknife_stats(f::Function, jk_sample_sets::AbstractVector{<:Real}...)

Compute the bias-corrected jackknife estimate and error of a (possibly nonlinear) function f of one or more primary observables, given their jackknife sample sets.

f is evaluated once per jackknife replicate i, taking the i-th sample from each set in jk_sample_sets (as produced by jackknife_samples) as its arguments. The jackknife error accounts for correlations between the observables and for nonlinearity in f, unlike simple error propagation.

The reported value is the bias-corrected jackknife estimator n·f(full) − (n−1)·mean(f_i), where f(full) is f evaluated on the full-sample values and f_i are the leave-one-out replicates. For linear f this reduces to f(full); for nonlinear quantities (susceptibility, specific heat, Binder cumulant) it removes the O(1/n) jackknife bias that matters at small bin counts.

The full-sample value of each observable is the mean of its jackknife sample set (the leave-one-out samples average back to the full-sample mean), so f needs no separate pass over the bin data.

Arguments

  • f: A function of length(jk_sample_sets) real arguments, computing the derived quantity from one sample of each underlying observable.
  • jk_sample_sets: One or more jackknife sample vectors (e.g. from jackknife_samples), all of equal length.

Throws

ArgumentError if no sample sets are provided, if the sample sets have different lengths, or if fewer than two jackknife replicates are provided.

Returns

A (value, error) tuple: the bias-corrected jackknife estimate of f, and its jackknife standard error.

UnitCellMC.analyze — Function
analyze(container::MeasurementContainer, T, N)

Compute primary and derived statistics for all observables recorded in container.

Primary observables (container.data) are reduced to (average, error) pairs via average_and_error and to jackknife sample sets via jackknife_samples. Derived quantities (container.derived) are then computed from the jackknife samples by calling each derived entry's compute function with the jackknife samples, T, and N, and merging the results into a single named tuple; this allows derived quantities (e.g. connected correlations, susceptibilities) to correctly propagate errors from one or more primary observables via jackknife resampling.

Arguments

  • container: A MeasurementContainer holding per-bin data for each observable (container.data) and a list of derived-quantity specifications (container.derived), each with a compute(jk, T, N) function.
  • T: Temperature, passed through to each derived quantity's compute.
  • N: System size (or other size parameter), passed through to each derived quantity's compute.

Throws

ArgumentError if any observable has fewer than two completed bins (e.g. a container that was never filled by a run).

Returns

A named tuple (primary = ..., derived = ..., autocorrelation = ...):

  • primary: Dict mapping observable name to its (average, error) pair.
  • derived: Named tuple merging the results of every derived quantity's compute call.
  • autocorrelation: Dict mapping each observable or diagnostic whose time series was recorded (see the time_series keyword of MeasurementContainer; by default the scalar ones) to an AutocorrelationResult for its per-measurement time series (see autocorrelation). Times are in units of measurements, i.e. n_unmeasured + 1 sweeps. The binned error bars in primary/derived are reliable only when bin_size is large compared with tau; as a rule of thumb keep bin_size >= 10 tau.

Reweighting

UnitCellMC.ReweightingResult — Type
ReweightingResult

Result of Ferrenberg–Swendsen single-histogram reweighting of one run's measurements to nearby temperatures (see reweight).

All conventions match analyze: energy and magnetization are per-site values, while specific_heat and susceptibility are the fluctuation formulas N(⟨e²⟩ − ⟨e⟩²)/T² and N(⟨m²⟩ − ⟨m⟩²)/T evaluated on the reweighted per-site moments (i.e. per-site heat capacity and susceptibility). Every value has a paired _err field holding its jackknife standard error.

Fields

  • T_sim::Float64: Temperature the simulation was run at.
  • temperatures::Vector{Float64}: The reweighted target temperatures.
  • n_sites::Int: The system size N used in the Boltzmann weights.
  • energy::Vector{Float64}: Reweighted per-site energy ⟨e⟩(T).
  • energy_err::Vector{Float64}: Jackknife error of energy.
  • specific_heat::Vector{Float64}: Reweighted N(⟨e²⟩ − ⟨e⟩²)/T².
  • specific_heat_err::Vector{Float64}: Jackknife error of specific_heat.
  • magnetization::Union{Nothing, Vector{Float64}}: Reweighted per-site magnetization ⟨m⟩(T) of the chosen series; nothing when reweighting was called with magnetization = nothing.
  • magnetization_err::Union{Nothing, Vector{Float64}}: Jackknife error of magnetization.
  • susceptibility::Union{Nothing, Vector{Float64}}: Reweighted N(⟨m²⟩ − ⟨m⟩²)/T of the chosen series; nothing when magnetization is nothing.
  • susceptibility_err::Union{Nothing, Vector{Float64}}: Jackknife error of susceptibility.
  • n_eff::Vector{Float64}: Effective number of samples, (Σ w)² / Σ w², per target temperature. Outside the histogram-overlap window this collapses toward a single sample; distrust targets whose n_eff is much smaller than the number of measurements (see reweight).

UnitCellMC.reweight — Function
reweight(container, T_sim, temperatures, N; magnetization = :magnetization, energy = :energy)

Reweight the measurements of a simulation run at temperature T_sim to the nearby temperatures in temperatures, using Ferrenberg–Swendsen single-histogram reweighting [1].

Each recorded measurement t, taken at inverse temperature β_sim = 1 / T_sim, is assigned the Boltzmann weight ratio

\[w_t(\beta) = \exp\!\big((\beta_{sim} - \beta)\, E_t\big),\]

where E_t = N · e_t is the total energy of the sample and e_t the recorded per-site value. Thermal averages at β = 1 / T follow as the weighted ratios ⟨A⟩(T) = Σ_t w_t A_t / Σ_t w_t. From the reweighted moments of the per-site energy (and magnetization, when requested) the specific heat N(⟨e²⟩ − ⟨e⟩²)/T² and susceptibility N(⟨m²⟩ − ⟨m⟩²)/T are computed with the same conventions as analyze, so reweighting to T_sim itself reproduces the direct analysis up to roundoff.

Error bars are jackknife estimates over the container's bins: consecutive blocks of bin_size measurements play the role of the bins, and every weighted ratio is recomputed leaving one block out (via jackknife_stats), which propagates the correlations between the weight sums and the observable moments. As with analyze, the blocks must span many autocorrelation times for the errors to be reliable.

Reweighting only interpolates within the sampled energy histogram: it is reliable while |β − β_sim| σ_E ≲ 1 (with σ_E the total-energy standard deviation at T_sim), i.e. roughly |T − T_sim| ≲ T_sim / √(N c_v). The returned n_eff — the effective number of samples, (Σ w)² / Σ w² — collapses toward a single histogram entry outside that window; distrust targets whose n_eff is much smaller than the number of measurements.

Arguments

  • container: A filled MeasurementContainer whose :energy time series was recorded (the default time_series = :scalars records it).
  • T_sim: The temperature the run was performed at.
  • temperatures: The target temperatures to reweight to.
  • N: The number of sites, used to convert the recorded per-site energies to total energies in the weights (same role as in analyze).
  • energy: Name of the recorded per-site energy time series to reweight (default :energy). A model recording its energy under a different name passes it here; the values must be per-site (the weights use E_t = N · e_t).
  • magnetization: Name of the recorded magnetization time series to reweight, or nothing to skip magnetic quantities. The default :magnetization is the signed magnetization for IsingModel and the magnetization magnitude for XYModel, ClockModel, and HeisenbergModel; the reweighted susceptibility is then N(⟨m²⟩ − ⟨m⟩²)/T of that series, which for the planar models differs from the component susceptibility of analyze (pass e.g. magnetization = :magnetization_x for one Cartesian component). For the Ising model below T_c, :abs_magnetization is the more useful choice (record it via measurements = [:abs_magnetization]).

Throws

ArgumentError if T_sim or any target temperature is not positive, if N is not positive, if the container holds fewer than two completed bins, if the energy (or requested magnetization) time series was not recorded, or if a time series length is inconsistent with the completed bins (e.g. a partially filled container).

Returns

A ReweightingResult with one entry per target temperature, in the order of temperatures.

[1] A. M. Ferrenberg and R. H. Swendsen, "New Monte Carlo technique for studying phase transitions", Phys. Rev. Lett. 61, 2635 (1988); "Optimized Monte Carlo data analysis", Phys. Rev. Lett. 63, 1195 (1989).

Autocorrelation

UnitCellMC.AutocorrelationResult — Type
AutocorrelationResult

Result of an autocorrelation analysis of one observable's Monte Carlo time series.

All times are in units of the sampling interval of the series. For the time series recorded by measure! that is one measurement, i.e. n_unmeasured + 1 sweeps (see SimulationParameters); for a pilot run with n_unmeasured = 0 (as in autotune_binning) it is one sweep.

Fields

  • tau::Float64: Integrated autocorrelation time τ_int = 1/2 + Σ_{k=1}^{K} ρ(k), with K chosen by self-consistent windowing. With this convention uncorrelated samples have τ_int = 1/2 and the variance of the sample mean is 2 τ_int σ² / n. Finite when status is :resolved or :anticorrelated, NaN otherwise.
  • tau_err::Float64: Statistical error of tau from the Madras–Sokal formula max(τ_int, 1/2) √(2(2K + 1)/n).
  • acf::Vector{Float64}: Normalized autocorrelation function ρ(k) for k = lags, with ρ(0) = 1. It is computed only up to the window K (or up to the maximum lag when unresolved), not over the whole series.
  • lags::Vector{Int}: Lags 0, 1, … corresponding to acf.
  • n::Int: Number of samples in the series (summed over all chains).
  • window::Int: The self-consistent window K (0 unless the window condition was met, i.e. status is :resolved or :anticorrelated).
  • status::Symbol: One of
    • :resolved: tau is a valid estimate;
    • :anticorrelated: tau is significantly below 1/2 (tau + 2 tau_err < 1/2), i.e. successive samples are anticorrelated. This happens e.g. for the signed magnetization under cluster updates, which flip the sign of a large cluster every step. The true value lies in (0, 1/2) but the windowed estimate is unreliable (it may even be negative); naive or binned error bars are then conservative, so for binning purposes such an observable behaves like uncorrelated data;
    • :unresolved: the window condition was never met within the maximum lag, i.e. the series is too short compared to its autocorrelation time. acf then holds the computed lags, and 0.5 + sum(acf[2:end]) is a lower-bound estimate of tau;
    • :constant: the series never changes (e.g. the energy of a frozen configuration), so there are no fluctuations to correlate;
    • :insufficient_data: fewer than two samples;
    • :unsupported: the element type cannot be analyzed.

For vector-valued observables (e.g. a correlation function), every non-constant component is analyzed separately and the result for the slowest component is returned: an unresolved component takes precedence, otherwise the component with the largest tau.

source
UnitCellMC.autocorrelation — Function
autocorrelation(series; max_lag = nothing, window = 6.0, chain_lengths = nothing)

Estimate the integrated autocorrelation time of one observable's time series with Sokal's self-consistent window: τ_int(K) = 1/2 + Σ_{k=1}^{K} ρ(k) is accumulated lag by lag and the sum stops at the first K with K ≥ window × τ_int(K). The default window = 6 is appropriate for roughly exponential decay; use a larger value for slowly decaying tails.

series may be scalar (AbstractVector{<:Real}) or vector-valued (AbstractVector{<:AbstractVector{<:Real}}, e.g. a correlation function sampled at several displacements). Vector-valued series are analyzed per component and the slowest non-constant component is reported (see AutocorrelationResult). Complex series, scalar or vector-valued (e.g. the structure factor), are analyzed with real and imaginary parts as separate components.

Keywords

  • max_lag: Largest lag considered. Defaults to one tenth of the shortest chain; if the window condition is not met by then the result is :unresolved.
  • window: Window constant c in K ≥ c τ_int(K).
  • chain_lengths: Lengths of independent chains concatenated in series (e.g. several runs merged by merge_containers); lagged products never straddle two chains.

A constant series returns a :constant result rather than throwing.

Throws

ArgumentError if window <= 0, if max_lag < 1, if chain_lengths has nonpositive entries or does not sum to length(series), or if vector-valued samples have unequal lengths.

Returns

An AutocorrelationResult.

source
UnitCellMC.autocorrelation_function — Function
autocorrelation_function(x; max_lag = length(x) ÷ 2, chain_lengths = nothing)

Compute the normalized autocorrelation function of a scalar time series,

ρ(k) = Σ_i (x[i] - x̄)(x[i + k] - x̄) / Σ_i (x[i] - x̄)²,   ρ(0) = 1,

using the standard (biased, 1/n-normalized) estimator, which has lower variance than the 1/(n - k) form and is the usual choice for windowed estimates of the integrated autocorrelation time.

If x is the concatenation of several independent Markov chains, pass their lengths in chain_lengths: lagged products are then only formed within each chain (the mean x̄ is still the global mean).

A max_lag larger than the longest chain minus one is clamped (longer lags pair no samples).

The cost is O(length(x) * max_lag) — quadratic in the series length at the default — so for long series prefer autocorrelation, which sums only up to an adaptively windowed lag (capped at a tenth of the shortest chain).

Returns

(lags, acf) with lags = 0:max_lag (after clamping) and acf[k + 1] = ρ(k).

Throws

ArgumentError if x has fewer than two samples or is constant, if max_lag < 1, or if chain_lengths is inconsistent with x.

UnitCellMC.recommended_binning — Function
recommended_binning(tau; bin_factor = 10, n_unmeasured = nothing)

Turn an integrated autocorrelation time tau, measured in sweeps (i.e. from a series sampled every sweep, as produced by autotune_binning), into a suggested (bin_size, n_unmeasured).

  • n_unmeasured: if not given, measurements are spaced s = max(1, round(tau)) sweeps apart, i.e. n_unmeasured = s - 1. Closer spacing would add little information per measurement, wider spacing would discard it. Pass n_unmeasured explicitly to keep a spacing of your choice (e.g. 0 when measurements are cheap).
  • bin_size: the number of measurements per bin, chosen so that each bin spans bin_factor integrated autocorrelation times in units of measurements: bin_size = ceil(bin_factor × τ_meas), where τ_meas = 1/2 + (tau - 1/2)/s is an upper bound on the integrated time of the thinned series (valid whenever the autocorrelation function is non-increasing; it tends to 1/2 once measurements are effectively independent). Bins spanning many τ_meas are nearly independent, so the binned/jackknife errors are reliable; the residual relative underestimate of the variance is of order τ_meas / bin_size.

tau below 1/2 (anticorrelation) is treated as 1/2.

Returns

A named tuple (bin_size = ..., n_unmeasured = ...). Choose the production n_measurements = bin_size × n_bins for the desired number of bins.

Throws

ArgumentError if tau is not finite and positive (an unresolved NaN autocorrelation time means the pilot run was too short; there is no safe default), if bin_factor is not positive, or if n_unmeasured is negative.

source
UnitCellMC.MeasurementContainer — Type
MeasurementContainer{D, N, T, S, Ts, O}

Accumulates binned Monte Carlo measurements and holds the observable specifications needed to analyze them.

The type parameters D (diagnostic names) and N (raw observable names) are tuples of Symbols, and O is the concretely typed tuple of Observables, so that measure! is type-stable: observable values are sampled, named, and accumulated without dynamic dispatch.

Raw measurements are accumulated into bin_sums and flushed into data once every bin_size measurements.

Fields

  • data::T: Per-observable completed bin values (e.g. a NamedTuple mapping observable name to a vector of per-bin averages), accumulated by measure! and consumed by analyze.
  • bin_sums::S: Per-observable running sums for the bin currently being accumulated, reset each time a bin is flushed into data.
  • time_series::Ts: Per-observable unbinned history of every measurement, kept for autocorrelation analysis in analyze. Successive entries are n_unmeasured + 1 sweeps apart. Only the observables selected by the constructor's time_series keyword are recorded (by default the scalar ones), so its keys are a subset of those of data.
  • chain_lengths::Vector{Int}: Lengths of the independent Markov chains concatenated in time_series when containers are combined with merge_containers; empty for a single run. Samples measured after the last recorded boundary (a merged container measured into further) count as one more chain — see chain_lengths_with_tail.
  • bin_count::Int: Number of measurements accumulated in the current bin; reset to 0 when the bin is flushed into data.
  • bin_size::Int: Number of measurements per bin (n_measurements ÷ n_bins).
  • observables::O: The raw observables being measured, stored as a concretely typed tuple whose names and order match the leading fields of bin_sums (the trailing fields are the diagnostics named by D).
  • derived::Vector{DerivedObservable}: The derived quantities to compute from the raw observables once binning is complete.

Construct with MeasurementContainer(model, geometry, n_measurements, n_bins; measurements).

UnitCellMC.correlation_instantaneous — Function
correlation_instantaneous(model, state, disp)

Compute one instantaneous sample of the correlation function for state, one value per displacement class in disp, by direct summation over site pairs. On fully periodic lattices the much cheaper correlation_instantaneous_dft is used instead; this direct path remains for open boundary conditions (and as the reference for tests).

For each displacement class r, averages operator_product(model, ...) over every valid starting site (site i, orbital oi) paired with its partner at the class's displacement (site j, orbital oj), wrapping coordinates with periodic boundary conditions where applicable, and dividing by the class's site count for a proper average.

Arguments

  • model: The model providing operator_product.
  • state: The current configuration, read via local_operator.
  • disp: Displacement class data as returned by build_displacement_classes, giving geometry, displacements, orbitals, valid_ranges, and counts.

Returns

A Vector{Float64} of length length(disp.displacements), one correlation value per displacement class, in the same order as disp.

source
UnitCellMC.correlation_instantaneous_dft — Function
correlation_instantaneous_dft(model, state, grid, index_map, inv_phases)

Compute one instantaneous sample of the correlation function on a fully periodic lattice via the Wiener–Khinchin theorem: the correlation function is the inverse discrete Fourier transform of the structure factor,

C_ab(Δ) = (1/N_c) Σ_k S_ab(k) e^{ik·Δ}.

The sample costs the same separable DFT as structure_factor_instantaneous, O(Nc Σd L[d]), once forward and once back — instead of the O(Nc · ndisplacements) direct sum of correlation_instantaneous, which remains in use for open boundary conditions (no translation invariance there).

Arguments

  • model: The model (through structure_factor_instantaneous's hooks).
  • state: The current configuration.
  • grid: Momentum data from build_momentum_grid (phases, grid sizes).
  • index_map: Map from displacement-class index (ordered as build_displacement_classes) to the flat (orbital-pair, Δ) layout of the inverse transform; built once in correlation_entry.
  • inv_phases: The inverse-DFT matrices from inverse_phases. Geometry-constant, so repeated sampling should precompute them once (as correlation_entry does); the four-argument form recomputes them every call.

Returns

A Vector{Float64} with one correlation value per displacement class, in the same order as correlation_instantaneous.

source
UnitCellMC.inverse_phases — Function
inverse_phases(grid)

Return the per-dimension inverse-DFT matrices for a momentum grid from build_momentum_grid: inv_phases[d] = grid.phases[d]' ./ L[d], the conjugate transpose of the forward Fourier matrix with the 1 / L[d] inverse-transform normalization. Geometry-constant — precompute once per geometry and pass to correlation_instantaneous_dft rather than rebuilding per measurement (see correlation_entry).

UnitCellMC.correlation_entry — Function
correlation_entry(model, geometry)

Build the raw and derived observable entries needed to measure the correlation function of model on geometry.

Precomputes the displacement classes once (via build_displacement_classes) and wraps them in an Observable named :correlation, sampled per measurement with correlation_instantaneous_dft on fully periodic lattices (the inverse-DFT / Wiener–Khinchin path) and with the direct sum correlation_instantaneous on lattices with any open dimension; and a DerivedObservable that computes the connected correlation via jackknife resampling (see jackknife_stats), subtracting the per-orbital magnetization product ⟨S_oi⟩·⟨S_oj⟩ of each class's orbital pair (summed over operator components) from the :magnetization_per_orbital observable (see magnetization_per_orbital_entry) — not the lattice-averaged ⟨m⟩², which is only correct when the sublattices are equivalent. The result also includes the CorrelationClass list labeling each entry.

The connected subtraction is exact only on fully periodic lattices: each class's raw average runs over its valid starting cells, and the whole-lattice per-orbital magnetization product matches the corresponding valid-cell average only when translation invariance makes per-orbital magnetizations uniform. With open dimensions, boundary sites magnetize differently from bulk sites and the subtraction is inexact — exact enumeration on a small open lattice shows discrepancies large enough to flip signs. Requesting :connected_correlation for a lattice with any open dimension therefore throws an ArgumentError at container construction.

Arguments

  • model: The model to measure correlations for.
  • geometry: The lattice geometry.

Returns

An (observable, labels, connected) tuple:

  • observable: An Observable for :correlation, sampling a Vector{Float64} (one value per displacement class) each measurement.
  • labels: A DerivedObservable passing the CorrelationClass list through to the analysis results as :correlation_classes, so that even a raw-correlation-only run labels its saved columns (see correlation_rows).

UnitCellMC.structure_factor_instantaneous — Function
structure_factor_instantaneous(model, state, momenta)

Compute one instantaneous sample of the orbital-resolved structure factor

\[S_{ab}(\mathbf{k}) = \frac{1}{N_c} \sum_\alpha \overline{\rho^\alpha_a(\mathbf{k})}\, \rho^\alpha_b(\mathbf{k}), \qquad \rho^\alpha_a(\mathbf{k}) = \sum_{\mathbf{R}} S^\alpha_{\mathbf{R},a}\, e^{-i\mathbf{k}\cdot\mathbf{R}},\]

where R runs over the N_c unit cells, a, b are orbitals, and S^α_{R,a} are the operator_components of the local operator on that site. On a periodic lattice this equals Σ_Δ C_ab(Δ) exp(-i k·Δ), the Fourier transform of the correlation function from correlation_instantaneous. Phases use unit-cell positions only; the orbital basis offsets are not included.

Arguments

  • model: The model providing operator_components.
  • state: The current configuration, read via local_operator.
  • momenta: Momentum data from build_momentum_classes.

Returns

A Vector{ComplexF64} with one entry per class in momenta.classes, in the same order. Diagonal orbital entries (a == b) are real and non-negative; S_ba(k) == conj(S_ab(k)).

UnitCellMC.clock_order_parameter_entry — Function
clock_order_parameter_entry(model, geometry)

Build the optional angular order parameter of a ClockModel.

The raw observable :clock_order_parameter is the instantaneous cos(q φ_M) from clock_angle_order (an O(N) resum of the magnetization per measurement), where φ_M is the direction of the total magnetization. Its average ⟨cos(q φ_M)⟩ tends to 1 when the magnetization locks onto one of the q clock directions and to 0 when its direction is uniformly distributed, so for q >= 5 it separates the low-temperature ordered phase from the intermediate critical phase, and its rise sharpens with system size at the lower transition.

No derived quantity is added: cos(q φ_M) is not a sum of local terms, so a fluctuation "susceptibility" N * Var / T would only reflect the trivial variance 1/2 of a uniformly distributed angle, growing with N throughout the disordered phase.

Arguments

  • model: The ClockModel being measured; supplies q.
  • geometry: The lattice geometry (unused; kept for the common entry signature).

Returns

An (obs, der) tuple: obs holds the :clock_order_parameter observable and der is empty.

Throws

ArgumentError if model is not a ClockModel.

UnitCellMC.helicity_modulus_entry — Function
helicity_modulus_entry(model, geometry)

Build the optional helicity-modulus (spin-stiffness) measurement for a vector-spin model (XYModel, ClockModel, HeisenbergModel).

The helicity modulus is the response of the free energy to an infinitesimal uniform twist of the spins along spatial direction d,

\[\Upsilon_d = \frac{1}{N} \left\langle \sum_{\langle ij \rangle} J_{ij} (\Delta r_{ij})_d^2 \big[ \mathbf{u}_i \cdot \mathbf{u}_j - (\mathbf{u}_i \cdot \hat{z}) (\mathbf{u}_j \cdot \hat{z}) \big] \right\rangle - \frac{\beta}{N} \left( \langle I_d^2 \rangle - \langle I_d \rangle^2 \right), \quad I_d = \sum_{\langle ij \rangle} J_{ij} (\Delta r_{ij})_d \big( \mathbf{u}_i \times \mathbf{u}_j \big)_z ,\]

where u_i is the unit spin vector of site i, the sums run over unique bonds, and Δr_ij is the real-space displacement vector of a bond (see bond_displacement). The twist is taken about the spin-space z axis; for the two-component models (XY, clock) this is the only choice, and for the Heisenberg model every axis is equivalent at zero field. The stiffness factor in brackets is the second twist derivative of the bond energy, helicity_stiffness_product; its (u · ẑ)(u · ẑ) term vanishes identically for the planar XY/clock spins and matters only for the Heisenberg model. In the XY/clock models a nonzero Υ signals the quasi-ordered phase, and the Berezinskii-Kosterlitz-Thouless transition is located by the universal jump Υ(T_BKT) = 2 T_BKT / π.

The estimator is intended for zero external field: a uniform twist also rotates the spins relative to the field axis, a contribution that is not included here.

Raw observables

  • :helicity_stiffness: The first ("kinetic") sum, per site — a length-D vector, one entry per spatial direction.
  • :helicity_current: The twist current I_d / N, per site.
  • :helicity_current_squared: (I_d / N)^2, sampled per measurement so that ⟨I_d²⟩ is available for the fluctuation term.

Arguments

  • model: The model being measured; must implement n_operator_components (used for the spin dot/cross products) with at least two spin components.
  • geometry: The lattice geometry, supplying the neighbor table and the bond displacement vectors.

Throws

ArgumentError if model has fewer than two spin components (e.g. IsingModel, for which the helicity modulus is not defined), or if geometry has no bonds.

Returns

An (obs, der) tuple: obs holds the three raw observables above and der the derived :helicity_modulus/:helicity_modulus_err (length-D vectors, per site, with jackknife errors from jackknife_stats).

source
UnitCellMC.helicity_stiffness_product — Function
helicity_stiffness_product(::HeisenbergModel, a, b)

The Heisenberg specialization of helicity_stiffness_product, the per-bond spin factor of the helicity-modulus stiffness sum. With the twist taken about the spin-space z axis, the second twist derivative of the bond energy $-J \, \mathbf{u}_i \cdot \mathbf{u}_j$ carries the factor $\mathbf{u}_i \cdot \mathbf{u}_j - (\mathbf{u}_i \cdot \hat{z}) (\mathbf{u}_j \cdot \hat{z})$, so the z components drop out: a[1] * b[1] + a[2] * b[2]. Spins aligned with the twist axis contribute no stiffness, as rotations about z leave them invariant.

helicity_stiffness_product(model, a, b)

Return the per-bond spin factor of the helicity-modulus stiffness sum — the second derivative of the bond energy under a uniform twist about the spin-space $z$ axis, divided by the coupling — given the local operator values a and b of the bond's endpoints (see helicity_modulus_entry). For a vector-spin model with bond energy $-J_{ij} \, \mathbf{u}_i \cdot \mathbf{u}_j$, rotating one endpoint of a bond by an infinitesimal angle about $\hat{z}$ gives

\[\mathbf{u}_i \cdot \mathbf{u}_j - (\mathbf{u}_i \cdot \hat{z}) (\mathbf{u}_j \cdot \hat{z}).\]

The default returns operator_product (the plain dot product), which is exact for models whose spins have no component along the twist axis, such as the planar XYModel and ClockModel. Models whose spins leave the $xy$ plane must specialize it, as HeisenbergModel does.
