UnitCellMC.build_displacement_classes — Function
build_displacement_classes(geometry::Geometry{D}) where D

Enumerate the distinct (orbital pair, displacement) classes for geometry, along with the range of valid starting sites for each class under the lattice's boundary conditions.

For every pair of orbitals (oi, oj) and every displacement Δl (in unit cell coordinates, one component per dimension), this computes the set of starting-site coordinates for which the site at Δl offset from the start remains within the lattice. Along periodic dimensions the full range 0:(L[d]-1) is always valid; along open (non-periodic) dimensions the range is clipped so that both the starting site and its displaced partner lie in-bounds. Classes with zero valid starting sites (only possible along an open dimension) are skipped.

This is typically used to precompute, once per geometry, the bookkeeping needed to average a correlation function over all equivalent site pairs at a given orbital pair and displacement.

Arguments

  • geometry: A Geometry{D} providing the unit cell (for orbital count) and lattice (for dimensions L and per-dimension periodicity periodic).

Returns

A named tuple with matching-length vectors describing each class, plus the source geometry:

  • displacements: The displacement Δl (an NTuple{D,Int}) for each class.
  • orbitals: The (oi, oj) orbital index pair for each class.
  • valid_ranges: Per-dimension UnitRange{Int} of valid starting-site coordinates for each class.
  • counts: Number of valid starting sites for each class (the product of valid_ranges lengths).
  • geometry: The source geometry, passed through unchanged (so consumers can use site_at and the lattice's boundary conditions).

UnitCellMC.build_momentum_grid — Function
build_momentum_grid(geometry::Geometry{D}) where D

Precompute, once per geometry, the momentum grid and lookup tables needed for momentum-space measurements such as the structure factor (which wraps this in build_momentum_classes to attach per-entry labels).

The momentum grid has L[d] points along each periodic dimension and a single point (k_d = 0) along each open dimension, matching LatticeUtilities.calc_k_points. Momenta are ordered in column-major order (first dimension fastest), the same ordering as build_displacement_classes.

Arguments

  • geometry: A Geometry{D} providing the unit cell and lattice.

Returns

A named tuple with fields

  • momentum_indices::Vector{NTuple{D,Int}}: Integer location n of each momentum on the grid, k = Σ_d (n[d] / L[d]) b_d with b_d the reciprocal lattice vectors.
  • momenta::Vector{NTuple{D,T}}: The Cartesian momentum k of each grid point.
  • sites::Vector{Array{Int,D}}: For each orbital, the site index of that orbital in the unit cell at location l stored at sites[o][(l .+ 1)...].
  • phases::NTuple{D,Matrix{ComplexF64}}: Per-dimension Fourier matrices, phases[d][n + 1, l + 1] = exp(-2πi n l / L[d]) (a single row of ones along open dimensions).
  • n_cells::Int: Number of unit cells, used for normalization.
  • n_orbitals::Int: Number of orbitals per unit cell.
  • n_momenta::Int: Number of momenta on the grid.

UnitCellMC.NeighborInfo — Type
NeighborInfo

A named tuple type recording, for a given site, the parallel lists of bond ids (bonds), the bond template each bond was generated from (templates), and the neighboring site reached by each bond (neighbors). bonds[k], templates[k] and neighbors[k] all refer to the same bond/neighbor triple, so the three vectors always have equal length.

templates[k] is bond_id_to_template[bonds[k]]: the id of the bond template (in bonds) that generated bond bonds[k]. It is stored per site as a per-bond payload index, so that inner loops can use it directly — for example to index a model's coupling vector — instead of going through bond_id_to_template on every neighbor visit.

UnitCellMC.Geometry — Type
Geometry{D,T<:AbstractFloat,N}

The lattice geometry for a D-dimensional model: unit cell, lattice, bonds, and the neighbor bookkeeping derived from them.

Fields

  • unit_cell::UnitCell{D,T,N}: The unit cell (orbital positions, basis vectors).
  • lattice::Lattice{D}: The lattice (system size, boundary conditions).
  • bonds::Vector{Bond{D}}: Bond templates defining the model's connectivity.
  • bond_id_to_template::Vector{Int}: Maps each concrete bond id to the index of the bond template (in bonds) it was generated from.
  • neighbor_table::Vector{NeighborInfo}: Indexed by site number, each entry gives the bonds, their bond templates, and the neighboring sites connected to that site.
  • n_sites::Int: Total number of sites in the lattice.

Construct with Geometry(unit_cell, lattice, bonds).

UnitCellMC.site_at — Function
site_at(geometry, loc, orbital)

Return the site index of orbital orbital in the unit cell at location loc (an NTuple of cell coordinates). A thin wrapper over LatticeUtilities.loc_to_site so that code outside the Geometry layer does not need that function's calling convention.

Returns

The site index (an Int).

UnitCellMC._cluster_labels — Function
_cluster_labels(geometry, clusters::Vector{Vector{Int}})

Translate an explicit partition of sites into per-site cluster labels: a vector labels of length geometry.n_sites with labels[i] = c for site i in clusters[c], and 0 for sites absent from the partition. Entries of clusters with indices above n_sites (ghost sites) are ignored.

Shared by the explicit-partition forms of apply_clusters!.
