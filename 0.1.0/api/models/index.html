UnitCellMC.AbstractModel — Type
AbstractModel{T<:Real}

Abstract supertype for the spin models simulated by this package (IsingModel, XYModel, ClockModel, HeisenbergModel).

Coupling layout contract

A model provides one bond coupling per bond template of the Geometry and one external-field value per unit-cell orbital, exposed through the couplings and fields accessors (by default the model's J and h fields). The checked bond_strength/field_strength lookups, the from-scratch energy sums, and every hot inner loop read couplings and fields through these accessors, so a model with a different storage layout overrides exactly these two functions (plus validate_model_geometry for its checks).

A model also declares its state type (state_type) and implements the single-site update contract (propose_value, energy_difference; apply_update! comes with the state), its observables (observables, derived_observables), and optionally the cluster-update hooks and binder_denominator.

UnitCellMC.XYModel — Type
XYModel{T<:Real} <: AbstractModel

The classical XY model with bond strengths J (one value per bond template) and external fields h (one value per site in the unit cell). The field points along the x direction, so its contribution is -h[i] * cos(angle[i]).

UnitCellMC.ClockModel — Type
ClockModel{T<:Real} <: AbstractModel

The q-state clock model: planar spins restricted to the q angles θ = 2π n / q, n ∈ 0:q-1, with Hamiltonian

H = -Σ_⟨ij⟩ J_ij cos(θ_i - θ_j) - Σ_i h_i cos(θ_i)

with bond strengths J (one value per bond template) and external fields h (one value per site in the unit cell). As for the XYModel, the field points along the x direction. q = 2 is the Ising model and q → ∞ approaches the XY model.

Fields

  • q::Int: Number of clock states.
  • J::Vector{T}: Bond strengths, one per bond template.
  • h::Vector{T}: External fields, one per site in the unit cell.
  • cosines::Vector{Float64}: Lookup table, cosines[n + 1] = cos(2π n / q).
  • sines::Vector{Float64}: Lookup table, sines[n + 1] = sin(2π n / q).

Construct with ClockModel(q, J, h).

source
UnitCellMC.HeisenbergModel — Type
HeisenbergModel{T<:Real} <: AbstractModel

The classical Heisenberg model: unit spin vectors $v_i \in S^2$ with bond strengths J (one value per bond template) and external fields h (one value per site in the unit cell), with Hamiltonian

H = -Σ_⟨ij⟩ J_ij (v_i · v_j) - Σ_i h_i x_i

The field points along the x direction, as for the XYModel and ClockModel. Spin components are stored directly in HeisenbergState, so bond energies are plain dot products and the Wolff/Swendsen-Wang cluster updates use the standard O(3) reflection embedding v ↦ v - 2 (v·r̂) r̂ about a random unit vector r̂.

Construct with HeisenbergModel(J, h); see Geometry for how bond templates map to the entries of J.

UnitCellMC.ClockClusterContext — Type
ClockClusterContext

Per-update state of a clock-model cluster move (Wolff or Swendsen-Wang).

The move reflects spins across one of the q mirror lines of the clock, n ↦ mod(mirror - n, q), which is the XY reflection θ ↦ 2φ + π - θ about the axis φ = π mirror / q - π/2; it maps clock states onto clock states.

Fields

  • mirror::Int: Mirror index in 0:q-1.
  • projections::Vector{Float64}: projections[n + 1] = cos(2π n / q - φ), the component of clock state n along the reflection axis.
  • ghost_projection::Float64: cos(φ), the axis component of the +x ghost spin (the -x ghost has -cos(φ)).
  • ghost_attached::Bool: Whether a Wolff cluster has bonded to a ghost spin, in which case it is not reflected.
source
UnitCellMC.XYClusterContext — Type
XYClusterContext

Per-update state of an XY cluster move (Wolff or Swendsen-Wang): the random reflection axis r̂ = (axis_cos, axis_sin) (stored both as the angle reflection_axis and as precomputed components, so projections p_i = v_i · r̂ need no trigonometric calls), and whether the growing Wolff cluster has bonded to a ghost spin (in which case it is not reflected).

UnitCellMC.rand_von_mises — Function
rand_von_mises(rng, κ)

Draw an angle in (-π, π] from the von Mises distribution p(θ) ∝ exp(κ cos θ), the single-site conditional of the XYModel under HeatbathAlgorithm up to rotation by the local-field direction.

Sampling uses the Best–Fisher rejection algorithm: with a = 1 + sqrt(1 + 4κ²), b = (a - sqrt(2a)) / (2κ), and r = (1 + b²) / (2b), draw z = cos(π u₁), set f = (1 + r z) / (r + z) and c = κ (r - f), and accept θ = ±acos(f) (sign fair) when c (2 - c) > u₂, else when log(c / u₂) + 1 ≥ c. For κ < 1e-8 the distribution is uniform to O(κ), so a uniform angle is returned directly (the κ → 0 limit of the general path is 0 / 0).

Throws

ArgumentError if κ < 0.

Returns

An angle in (-π, π] centered on direction 0.

UnitCellMC.random_unit_vector — Function
random_unit_vector(rng)

Draw a uniformly distributed unit vector in $\mathbb{R}^3$ (a random point on the unit sphere): with z uniform on [-1, 1] and φ uniform on [0, 2π), the vector (√(1 - z²) cos φ, √(1 - z²) sin φ, z) is uniform on the sphere. Shared by initialize_state, propose_value, and the cluster context of the HeisenbergModel, so all consume the same two draws per vector from rng.

Returns

A (x, y, z) tuple with x² + y² + z² == 1 to rounding.

UnitCellMC.validate_model_geometry — Function
validate_model_geometry(model, geometry)

Validate the compatibility between a model's coupling/field data and the lattice geometry. The generic method enforces the package-wide layout contract (see AbstractModel) through the accessors, so a model with a different storage layout is checked on the values it actually serves: the couplings vector must have one entry per bond template in geometry.bonds, and the fields vector must have one entry per unit-cell orbital. (The template ids in geometry.bond_id_to_template are valid by construction, so only lengths need checking.) Models with J and h fields (IsingModel, XYModel, ClockModel, HeisenbergModel) need no method of their own; a model that exposes neither the fields nor the accessors fails here instead of passing unvalidated.

Throws

ArgumentError if length(couplings(model)) or length(fields(model)) does not match the geometry.

Returns

nothing.

UnitCellMC.binder_denominator — Function
binder_denominator(model)

Return the denominator of the fourth-order Binder cumulant, 1 - ⟨m⁴⟩ / (binder_denominator * ⟨m²⟩²), for model's order parameter: 3 for a one-component (Ising) order parameter, 2 for a two-component (XY, or clock with q >= 3) one, 5/3 for a three-component (Heisenberg) one — the high-temperature Gaussian cumulant ratio. Required by the :binder_cumulant optional measurement.

Throws

ArgumentError for models without their own method; define binder_denominator(::MyModel) to enable :binder_cumulant.

UnitCellMC.clock_angle_order — Function
clock_angle_order(model::ClockModel, state::ClockState)

Return the instantaneous angular order parameter cos(q φ_M) of state, where φ_M = atan(M_y, M_x) is the direction of the total magnetization.

The magnetization is resummed from state.spins (O(N)) rather than read from the running totals. On small lattices M = 0 is a common configuration, and there the running totals hold only rounding residue whose direction is meaningless and grows with run length. A fresh sum is accurate to about N * eps(), so |M| <= √eps() is treated as zero, for which the direction is undefined and 0.0 is returned.

UnitCellMC.operator_components — Function
operator_components(model::AbstractModel, value)

Return the real components of the local operator value (as returned by local_operator) as a tuple of length n_operator_components(model).

The components must reproduce the model's two-body product,

operator_product(model, a, b) ≈ sum(operator_components(model, a) .* operator_components(model, b))

so that the structure factor is exactly the Fourier transform of the correlation function measured by correlation_instantaneous. For an Ising spin s this is (s,); for an XY spin the local value is already the unit vector (cos θ, sin θ), so this is the identity; for a clock index n it is (cos(2πn/q), sin(2πn/q)).

For models with at least two components, components 1 and 2 must be the spin's x and y Cartesian components (unit-normalized for a unit-spin model): the :helicity_modulus measurement reads the twist current (u_i × u_j)_z = u_i[1] u_j[2] - u_i[2] u_j[1] from them.

Throws

ArgumentError for models that do not implement the hook.

UnitCellMC.propose_value — Function
propose_value(rng, model, geometry, state, site)

The model hook behind every local-update algorithm's trial move: propose a new value for the degree of freedom at site (chosen by the algorithm's AbstractProposalScheme), given the frozen current state, and return it as a SpinUpdate carrying the value and the magnetization change the update would make.

Every model implements this once and thereby supports all local-update algorithms: the MetropolisAlgorithm and GlauberAlgorithm propose methods both fall back to it, as does any custom local-update algorithm whose six-argument propose does the same. A model may still override a specific algorithm's six-argument propose when it wants an algorithm-specific move (e.g. a different Glauber proposal).

Throws

ArgumentError if model does not define its own method. To support a custom model, define propose_value(rng, model::MyModel, geometry, state::MyState, site::Int) returning a SpinUpdate.

Returns

A SpinUpdate describing the site and its proposed new value.

UnitCellMC.energy_difference — Function
energy_difference(model, geometry, state, proposal)

Compute the change in total energy ΔE that would result from changing the spin at proposal.site to proposal.new_value, given the couplings and field in model.

Arguments

  • model: The IsingModel providing bond strengths and field h.
  • geometry: Lattice geometry giving each site's neighbors and bonds.
  • state: Current spin configuration.
  • proposal: A SpinUpdate describing the trial move.

Returns

The energy difference ΔE between the proposed and current configurations. For current spin s, proposed spin s_new, and local field H = h + sum(J * neighbor_spin), this is (s - s_new) * H.

source
energy_difference(model, geometry, state, proposal)

Compute the change in total energy ΔE that would result from changing the spin at proposal.site to proposal.new_value, given the couplings and field in model.

Written with the spin components v_i = (c_i, s_i) directly, so the neighbor loop is free of trigonometric calls: with Δv = v_new - v_old and the local field sums C = Σ J c_j, S = Σ J s_j over the site's bonds, ΔE = -(Δc * C + Δs * S) - h * Δc.

Returns

The energy difference ΔE between the proposed and current configurations.

source
energy_difference(model::ClockModel, geometry, state, proposal)

Compute the change in total energy ΔE from changing the clock index at proposal.site to proposal.new_value: with θ_n = 2πn/q, this is -Σ_j J_ij (cos(θ_new - θ_j) - cos(θ_old - θ_j)) over the site's neighbors, plus the field term -h (cos θ_new - cos θ_old) (the field points along the x direction).

Returns

The energy difference ΔE between the proposed and current configurations.

source
energy_difference(model::HeisenbergModel, geometry, state, proposal)

Compute the change in total energy ΔE that would result from changing the spin at proposal.site to proposal.new_value, given the couplings and field in model.

Written with the Cartesian components directly, so the neighbor loop is free of trigonometric calls: with Δv = v_new - v_old and the local field sums C_α = Σ J v_j,α over the site's bonds, ΔE = -Δv · C - h * Δx.

Returns

The energy difference ΔE between the proposed and current configurations.

UnitCellMC.validate_cluster_model — Function
validate_cluster_model(model, geometry, state, T)

Check that model can be updated by the cluster algorithms (WolffAlgorithm, SwendsenWangAlgorithm). step! runs it once per ClusterWorkspace — i.e. once per run, since drivers allocate one workspace per run — rather than before every step; a step! call without a workspace validates on every call.

The default enforces the cluster updates' core requirement — non-negative (ferromagnetic) couplings, so the bond-activation probabilities stay in [0, 1] — reading the couplings through the couplings accessor (see the layout contract under AbstractModel), so a model with a custom storage layout is checked on the values it actually serves rather than passing unvalidated. Models with extra structure extend this method with their own checks.

Throws

ArgumentError if any coupling is negative.

Returns

nothing.

UnitCellMC.apply_cluster! — Function
apply_cluster!(model, geometry, state, cluster)

Flip a Wolff cluster and update the cached Ising observables incrementally. Only bonds crossing the cluster boundary change energy: with pre-flip spins, a boundary bond (i, j) with i in the cluster contributes ΔE = 2 * J * spins[i] * spins[j], and each flipped site contributes a field term ΔE = 2 * h * spins[i] and ΔM = -2 * spins[i].

This form allocates a membership mask per call; the Wolff driver instead passes down the mask it already built.

source
apply_cluster!(model, geometry, state, cluster, reflection_axis)

Reflect a Wolff cluster about reflection_axis and update the cached XY observables incrementally. With p_i = v_i · r̂ the pre-reflection component of site i's spin along the axis r̂ = (cos φ, sin φ), a boundary bond (i, j) with i in the cluster contributes ΔE = 2 * J * p_i * p_j, and each reflected site contributes ΔE = 2 * h * cos(φ) * p_i, ΔM_x = -2 * cos(φ) * p_i, and ΔM_y = -2 * sin(φ) * p_i. The reflection itself is the linear map v ↦ v - 2 (v·r̂) r̂.

This form allocates a membership mask per call; the Wolff driver instead passes down the mask it already built.

apply_cluster!(model, geometry, state, cluster, axis)

Reflect a Wolff cluster about the unit vector axis (a nonzero 3-vector, normalized on entry) and update the cached Heisenberg observables incrementally. With p_i = v_i · r̂ the pre-reflection component of site i's spin along the axis r̂, a boundary bond (i, j) with i in the cluster contributes ΔE = 2 * J * p_i * p_j, and each reflected site contributes ΔE = 2 * h * r̂_x * p_i and ΔM_α = -2 * r̂_α * p_i. apply_clusters!(rng, model, geometry, state, workspace, context)

Randomly orient each Swendsen-Wang cluster and update the cached Ising observables incrementally via _flip_ising_clusters!. The orientation decisions are drawn by draw_cluster_flips! — one coin flip per cluster, in the first-encounter order of workspace.roots, with ghost-attached clusters never flipped — and recorded per root-id label in workspace.flip.

UnitCellMC._reflect_xy_clusters! — Function
_reflect_xy_clusters!(model, geometry, state, labels, flip, reflection_axis)

Reflect every lattice site whose cluster label is marked in flip, accumulating the exact energy and magnetization change. labels[i] is the union-find root of site i (see step! with SwendsenWangAlgorithm) and doubles as the site→cluster map: a bond incident to a reflected site is internal (both endpoints reflect, and the reflection v ↦ v - 2 (v·r̂) r̂ preserves their dot product) when flip[labels[neighbor]] is true, external (never visited) when neither endpoint reflects, and crossing (counted once, from the reflected side, with pre-reflection components) otherwise.

UnitCellMC._flip_ising_clusters! — Function
_flip_ising_clusters!(model, geometry, state, labels, flip)

Flip every lattice site whose cluster label is marked in flip, accumulating the exact energy and magnetization change. labels[i] is the union-find root of site i (see step! with SwendsenWangAlgorithm) and doubles as the site→cluster map: a bond incident to a flipped site is internal (both endpoints flip, no change) when flip[labels[neighbor]] is true, external (never visited) when neither endpoint flips, and crossing (counted once, from the flipped side, with pre-flip spins) otherwise.

UnitCellMC._reflect_clock_sites! — Function
_reflect_clock_sites!(model, geometry, state, sites, reflected, mirror)

Apply the clock reflection n ↦ mod(mirror - n, q) to every site in sites and accumulate the exact energy and magnetization change from the lookup tables. reflected[i] must be true exactly for the sites in sites.

Bonds with both endpoints reflected keep their energy (cos(θ_i - θ_j) is invariant under a common reflection), so only bonds crossing the boundary of the reflected set are visited; their far endpoint is never mutated, so pre- and post-reflection energies are evaluated directly as -J (cos(θ'_i - θ_j) - cos(θ_i - θ_j)).

UnitCellMC._reflect_clock_clusters! — Function
_reflect_clock_clusters!(model, geometry, state, labels, flip, mirror)

Reflect every lattice site whose cluster label is marked in flip across clock mirror mirror (n -> mod(mirror - n, q)), accumulating the exact energy and magnetization change from the lookup tables. labels[i] is the union-find root of site i (see step! with SwendsenWangAlgorithm) and doubles as the site-to-cluster map: a bond incident to a reflected site is internal (both endpoints reflect, and reflection preserves cos(θ_i - θ_j)) when flip[labels[neighbor]] is true, external (never visited) when neither endpoint reflects, and crossing (counted once, from the reflected side, with pre-reflection indices) otherwise. Sites lying on the mirror (new == old) do not move, so their incident bonds are unchanged and are skipped together with the site itself.

UnitCellMC._heatbath_cos_theta — Function
_heatbath_cos_theta(rng, κ)

Draw cos θ ∈ [-1, 1] from p(c) ∝ exp(κ c), the polar-angle density of the Fisher distribution, by inversion of the cumulative distribution: c = 1 + log(u + (1 - u) exp(-2κ)) / κ for u uniform on [0, 1). The written form factors out exp(κ), so it neither overflows nor loses range at large κ. For κ < 1e-8 the density is uniform to O(κ), so c = 2u - 1 avoids the 0 / 0 limit.

UnitCellMC._orthonormal_basis — Function
_orthonormal_basis(u)

Return unit vectors e1, e2 perpendicular to the unit vector u and to each other: e1 is the normalized cross product of u with the coordinate axis least aligned with it (the largest such cross product, so the normalization cannot degenerate), and e2 = u × e1.
